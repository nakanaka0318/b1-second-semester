1MIPS の復習:100MIPS で 1ms の間に実行できる命令数

MIPS = 1 秒間に実行できる命令数を 100万(106) 単位で表したもの。

MIPS = 実行命令数 ÷ (実行時間[秒] × 106)

1ms = 10−3 秒なので、

100 = 実行命令数 ÷ (10−3 × 106) = 実行命令数 ÷ 103
∴ 実行命令数 = 100 × 103 = 105(10万命令)

2位取り記数法(2章 2.1)

数字を書く「位置」によって重みが決まる書き方。n 進法では、位が1つ上がるごとに重みが n 倍になる。

2.1-1 整数(n 進法のとき)

X = am×nm + am−1×nm−1 + … + a1×n1 + a0×n0ai は 0〜(n−1) の数字。n0 = 1

2.1-2 小数(p 進法のとき)

N = d−1×p−1 + d−2×p−2 + … + d−m×p−m小数点の右は p−1, p−2, … と重みが 1/p ずつになる

例:10進数の 421 = 4×102 + 2×101 + 1×100。2進数の 1011 = 1×23 + 0×22 + 1×21 + 1×20 = 11。

4(2) 10進数 → 2進数

  • 整数部:2で割り続け、出た余りを記録する。商が 0 になったら終わり。余りを下から上へ読む。
    例:421 → 110100101(2)
  • 小数部:2を掛け続け、整数部分に出た 0 か 1 を記録する(1 が出たら取り除いて続ける)。小数部が 0 になれば有限回で終了。
    例:0.1 → 0.0001100110011…(2) の無限循環小数(終了しないこともある)。

  • 10 → 16:16 で割り続けて余りを下から読む。421 ÷ 16 = 26 余り 5、26 ÷ 16 = 1 余り 10(=A)、1 ÷ 16 = 0 余り 1 → 1A5
  • 16 → 10:位の重み 162=256, 161=16, 160=1 を掛けて足す。1A5 = 1×256 + 10×16 + 5 = 256 + 160 + 5 = 421

6(4) 16進数 ↔ 2進数、8進数 ↔ 2進数

  • 16 = 24 なので、16進数1桁は2進数 4 ビットにぴったり対応する(1111 = F)。
  • 8 = 23 なので、8進数1桁は2進数 3 ビットに対応する(111 = 7)。
  • 2進数から変換するときは、小数点(整数なら右端)から4ビット(または3ビット)ずつ区切る。足りない左端は 0 で埋める。
見るノートの例:16進数 E4A を8進数に

① 16進数を1桁ずつ4ビットに直す → ② 右端から3ビットずつ区切り直す → ③ 3ビットずつ8進数1桁に。左から区切ると「1 6 2 3 2」のように間違えるので注意(ノートで消してある計算)。
