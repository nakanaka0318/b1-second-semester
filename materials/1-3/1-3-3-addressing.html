    1.4-1アドレス

    用語意味
    絶対アドレス主記憶で記憶場所を示す番地そのもの
    実効アドレス命令やデータが実際に格納されているアドレス(中身は絶対アドレス)。アドレッシング方式によって計算して求める
    相対アドレス基点からの距離(差)でアドレスを表したもの
    試すC 言語の配列は相対アドレス:int room[5];

    配列名 room は先頭アドレス(基点)を表し、room[3] のアドレスは room + 3(基点から3つ先)です。int が4バイトなら、実際の番地は 先頭 + 3 × 4 になります。

    1.4-2アドレス空間

    • 1命令 = 1語の固定長命令なら、一般的にアドレス空間は1語のビット数で表せる範囲。
    • しかし命令にはオペコードも入るので、オペランドのビット数 < アドレス空間のビット数になる → オペランドだけでは全番地を指せない。
    計算ノートの例:16ビット固定長命令で、オペコードが4ビットの場合
    ビット

    だから、オペランドの値をそのまま番地として使うだけでなく、レジスタや PC と組み合わせて実効アドレスを作る工夫(アドレッシング方式)が必要になります。

    1.4-3アドレッシングの種類

    方式オペランドのアドレス部に入っているもの実効アドレス
    即値データそのもの。主記憶を参照せずに命令を実行なし(例外)
    直接アドレス指定処理対象データの主記憶アドレスX
    間接アドレス指定「データが格納された主記憶のアドレス」が格納された主記憶アドレス(直接と意味が違う)主記憶[X]
    レジスタアドレス指定レジスタ番号。そのレジスタに処理対象データの主記憶アドレスが入っているレジスタの値
    インデックス・アドレス指定2部構成:① レジスタ番号 ② 基点からの距離(変位)インデックスレジスタ + 変位
    自己相対アドレス指定PC からの距離PC の値 + アドレス部
    補足:教科書によっては、レジスタにデータそのものが入っている方式を「レジスタアドレス指定」、レジスタに番地が入っている方式(上の表・ノートの定義)を「レジスタ間接アドレス指定」と呼び分けることがあります。

    1.5記憶装置

    • 記憶容量と処理速度はトレードオフ(大容量なものほど遅く、速いものほど小容量・高価)→ 特性に応じて役割分担する。
    • 内部記憶装置:主記憶やキャッシュメモリ
    • 外部記憶装置:ハードディスクや USB メモリ
    • 記憶階層:CPU の近く → 高速(小容量)、CPU から遠く → 大容量(低速)
    見る記憶階層(タップで目安を表示)

    数値は一般的なパソコンでのおおよその目安です。

    1.6接続方式

    • バス接続方式:バス線に各装置の入力と出力を接続する。バス線は同時期に1つの装置しか使えない(バス線にデータを入れられるのは1台だけ)。
    • ノイマン・ボトルネック:CPU の処理能力を上げても、バスのデータ転送能力を上げないと、全体として性能が向上しない。

    問4 シミュレータで確認

    シミュレータの初期状態の主記憶で、X = 100 として直接アドレス指定なら R1 に入る値は?

    答え答えと解説

    答え:107

    実効アドレス = 100。主記憶[100] = 107。

    問5 シミュレータで確認

    同じく X = 100 で間接アドレス指定なら R1 に入る値は?

    答え答えと解説

    答え:58

    主記憶[100] = 107 が実効アドレス。主記憶[107] = 58。

    問6 相対アドレス

    int room[5]; の先頭アドレスが 1000 番地、int が4バイトのとき、room[3] の番地は?

    答え答えと解説

    答え:1012

    1000 + 3 × 4 = 1012。

    問7 アドレス空間

    16ビット固定長命令でオペコードが4ビットのとき、オペランドだけで指せる番地は何通り?

    答え答えと解説

    答え:4096

    オペランドは 12 ビット → 212 = 4096 通り(000〜FFF)。アドレス空間 16 ビット(0000〜FFFF、65536 通り)の 1/16 しか指せません。

    ノイマン・ボトルネックとは何か、説明しなさい。

    解答例解答例を見る

    ノイマン型コンピュータでは、CPU と主記憶の間の命令やデータのやり取りがバスを通るため、CPU の処理能力を上げても、バスのデータ転送能力を上げなければ、全体としての性能が向上しないこと。

    シミュレータの命令は説明用に作った架空のものです。記憶階層の数値はおおよその目安です。
