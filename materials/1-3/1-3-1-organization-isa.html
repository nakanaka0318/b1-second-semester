1.1-1基本モデル:ノイマン型コンピュータ

今のコンピュータのほとんどはノイマン型コンピュータです。特徴は2つです。

特徴意味
プログラム内蔵方式命令とデータを、どちらもメモリに格納しておく
逐次実行指定した順序で命令を1つずつ実行する
ポイント:プログラムも「メモリに置かれたデータ」の一種なので、メモリの中身を入れ替えるだけで別の仕事ができます。昔の計算機は配線をつなぎ替えてプログラムを変えていました。

1.1-2 5大構成要素

入力装置・記憶装置・演算装置・制御装置・出力装置の5つです。演算装置と制御装置をまとめたものが CPU です。ページ上部の図でそれぞれの役割を確認できます。

1.2-1機械語(マシン語)

  • 0 と 1 の2進表記で命令やデータを表す言語
  • 命令形式とよばれる規則的な形式がある
  • コンピュータが直接実行できる唯一の言語(コード)

1.2-2アセンブリ言語

  • 機械語の命令をニモニック(英単語の略語)で表したもの。例:LD(ロード=読み込み)、ADD(足し算)、ST(ストア=書き込み)
  • コンピュータは直接受け付けられないので、機械語に変換するアセンブラが必要
高級言語(C言語など)―コンパイラで翻訳→ アセンブリ言語―アセンブラで翻訳→ 機械語

命令は「オペコード」と「オペランド」でできている

部分意味数
オペコード命令操作コード。「〜しなさい」にあたる部分全ての命令に必ず1つ
オペランド操作の対象。レジスタや変数(のアドレス)命令によって異なる(0個のこともある)
試すC言語 → アセンブリ言語 → 機械語 の変換を見る

行にカーソルを合わせる(タップする)と、対応する行が光ります。青=オペコード、黄=オペランド。変数 a, b, c, d は主記憶の 0x0100, 0x0104, 0x0108, 0x010C 番地にあるとします。命令の形は説明用に作った架空のもの(32ビット固定長:オペコード8ビット+レジスタ8ビット+アドレス16ビット)です。

1.2-3コンピュータにおける命令セット

  • 命令セット=そのコンピュータ(CPU)が用意している命令の集まり。コンピュータごとに命令セットは異なる
  • 命令セットは、ソフトウェア(SW)から見えるコンピュータの仕様。命令セットが同じなら、SWから見て同じコンピュータに見える
  • そのため、コンピュータのハードウェア(HW)が異なっても、命令セットが同一なら同じプログラムが動く
身近な例:メーカーや世代が違うパソコンでも、CPUの命令セットが同じ(x86-64 など)なら、同じソフトがそのまま動きます。

1.2-4命令の長さ

命令の長さは語長が基準です。長さの決め方には2つの方式があります。

固定長命令(RISC)可変長命令(CISC)
長さ全ての命令の長さを固定命令の種類によって長さが変わる
考え方1つ1つの命令を単純にして高速処理1つの命令で複雑な処理を実現
自転車でたとえると軽いギア1でこぎまくる重いギア3で強くふんばる
見る命令の並び方のイメージ(1マス=1バイト)
固定長(RISC):全部4バイト → 次の命令の位置がすぐ分かる
可変長(CISC):1〜数バイトとまちまち → 解読してみないと次の位置が分からない

問8 教科書 P20 [1] アセンブリ言語と機械語

「アセンブリ言語」と「機械語」の違いを説明しなさい。

解答例解答例を見る

機械語は、命令やデータを 0 と 1 の2進表記で表した言語で、コンピュータが直接実行できる。アセンブリ言語は、機械語の命令を LD や ADD のようなニモニック(英単語の略語)で表した言語で、人が読み書きしやすいが、コンピュータは直接実行できないため、アセンブラによって機械語に変換してから実行する。

問9 教科書 P20 [2] 命令セットが同じ利点

コンピュータが異なるとき、命令セットが同じであることの利点を説明しなさい。

解答例解答例を見る

命令セットはソフトウェアから見たコンピュータの仕様なので、ハードウェアが異なっていても命令セットが同じであれば、同じ機械語のプログラムをそのまま実行できる。そのため、ソフトウェアを共通化でき、コンピュータごとにプログラムを作り直す必要がない。

「試す」の命令コードは説明用に作った架空の命令セットで、実在の CPU のものではありません。
