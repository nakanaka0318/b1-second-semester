3確率変数

標本空間 Ω の各根元事象に対応して、その値が定まるような変数を確率変数という。各値には一定の確率が付与される。

  • 確率変数は一般に大文字 X で表し、取りうる値は小文字 x(または x₁, x₂, …, xn)で表す。
  • 例:サイコロを投げて「出た目」を X とすると、Ω = {1の目, 2の目, …} の各根元事象に X = 1, 2, …, 6 が対応する。
イメージ:確率変数は「試行の結果 → 数」への対応(関数)です。同じサイコロ2個でも、「和」「大きい方」「差」など、何を X にするかで分布が変わります(ページ上部で切り替えられます)。

3.1離散的な場合

X が離散的で有限個の値をとるとする。X が xi(i = 1, 2, …, n)となる確率を P(X = xi) = pi とすると、

P(x) = { pi(x = xi のとき)、0(x ≠ xi のとき)}

と書ける。このように定めた関数を確率密度関数という。離散的な場合は確率関数とよぶことが多い。

例:正しいサイコロを1回投げる

X = 出た目とすると x₁ = 1, …, x₆ = 6。どれも P = 1/6。

X123456
P(x)1/61/61/61/61/61/6

このように、X の値と確率の対応をまとめたものを確率分布とよぶ。確率をすべて足すと必ず 1 になる。

定義分布関数

確率変数 X の値が x 以下である確率を表す関数

F(x) = P(X ≤ x) = Σxi ≤ x P(xi)

を分布関数という。離散的な場合の性質:

  1. F(x) = Σxᵢ≤x P(xᵢ)(x 以下の確率を全部足したもの)
  2. F(x) は階段状の関数で、F(−∞) = 0、F(∞) = 1
  3. P(α < X ≤ β) = F(β) − F(α) = Σα<xᵢ≤β P(xᵢ)

ページ上部で α と β を動かすと、P(x) の棒(濃い部分)を足したものと、F(β) − F(α) が同じになることを確かめられます。

問2つのサイコロの目の和

2つの正しいサイコロを投げる。確率変数 X を出た目の和とする。このときの分布を確率関数あるいは確率分布として示しなさい。

3.2連続的な場合

X が連続的な値をとり、その範囲が A ≤ X ≤ B であるとする。X が a と b の間(A ≤ a ≤ b ≤ B)にある確率は

P(a ≤ X ≤ b) = ∫ab p(x) dx

で求められる。この p(x) を確率密度関数という。確率は「曲線の下の面積」です。

  • 離散的な場合と違い、区間の端が含まれるかどうかは確率に関係しない:P(a ≤ X ≤ b) = P(a < X ≤ b) = P(a ≤ X < b) = P(a < X < b)。(1点の幅は 0 なので、1点の確率は 0)
  • すべての確率の和は 1:∫AB p(x) dx = 1、また ∫−∞∞ p(x) dx = 1(範囲外では p(x) = 0)。
  • 分布関数は F(x) = ∫Ax p(t) dt = ∫−∞x p(t) dt。

連続的な場合の分布関数の性質:

  1. F(x) = ∫−∞x p(t) dt
  2. F(x) は x について減少しない関数で、F(−∞) = 0、F(∞) = 1
  3. P(α < X ≤ β) = F(β) − F(α) = ∫αβ p(x) dx
試す面積 = 確率
確率密度関数 p(x)(塗った面積 = 確率)
分布関数 F(x)(なめらかに増える)

Q練習問題

分数か小数で入力して「判定」を押してください。

問1

2つのサイコロの目の和 X について、P(X = 7) は?

問2

同じく、分布関数の値 F(4) = P(X ≤ 4) は?

答え答えと解説

答え:1/6

(1 + 2 + 3)/36 = 6/36 = 1/6。

問3

同じく、P(3 < X ≤ 6) を F を使って求めよ。

答え答えと解説

答え:1/3

F(6) − F(3) = 15/36 − 3/36 = 12/36 = 1/3。直接足しても P(4)+P(5)+P(6) = (3+4+5)/36 = 12/36。

問4

一様分布 p(x) = 1(0 ≤ x ≤ 1)で、P(0.2 ≤ X ≤ 0.5) は?

問5

p(x) = 2x(0 ≤ x ≤ 1)のとき、P(X ≤ 0.5) は?

答え答えと解説

答え:1/4

∫00.5 2x dx = [x²]00.5 = 0.25。範囲の半分なのに確率は 1/4。密度が右ほど大きいからです。

問6 確率密度関数の条件

p(x) = cx(0 ≤ x ≤ 2)、それ以外で 0 が確率密度関数になるような定数 c は?

答え答えと解説

答え:1/2

∫02 cx dx = c[x²/2]02 = 2c = 1 より c = 1/2。「全確率 = 1」の条件を使います。
