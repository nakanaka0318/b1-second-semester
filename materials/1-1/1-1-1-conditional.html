独立な試行と条件付き確率

確率統計 第1回のノートのまとめです。「前の結果が次に影響しない」独立な試行と、「〜が起きたと分かっているとき」の条件付き確率を、手を動かしながら確かめます。後半に答え合わせできる練習問題があります。

行が 1個目、列が 2個目 の目。濃い青=A₁かつA₂、薄い青=A₁だけ、黄色の枠=A₁の外にあるA₂。条件付き確率は「薄い青+濃い青」の中で濃い青が占める割合です。
独立な試行反復試行の定理例題:点の移動条件付き確率乗法定理練習問題

2.1独立な試行

コイン投げやサイコロ投げのように、1回目の結果が2回目の結果に影響を与えない試行を独立な試行といいます。

2つの独立な試行の結果をそれぞれ A₁, A₂ とするとき、両方が起こる確率は掛け算で求まります。

P(A₁ ∩ A₂) = P(A₁) × P(A₂)独立事象の乗法定理
例:コインで表(1/2)、サイコロで6(1/6)が両方出る確率は 1/2 × 1/6 = 1/12。コインの結果はサイコロに影響しないので、掛けるだけでよい。
注意:袋から玉を戻さずに続けて取り出す場合は、1回目の結果で袋の中身が変わるので独立ではありません。この場合は後で出てくる乗法定理を使います。

定理反復試行(独立試行)の定理

1回の試行で事象が起こる確率を p、起こらない確率を 1−p とします。この試行を n 回独立にくり返すとき、ちょうど x 回起こる確率は

nCx px (1−p)n−xどの x 回で起こるかの選び方 × 1通りあたりの確率

ノートの例:サイコロを5回投げて、6の目がちょうど3回出る確率

p = 1/6、n = 5、x = 3 なので

5C3 (16)3(56)2 = 10 × 2565 = 1253888
試すn・p・x を変えてグラフで見る
理論値(棒をタップで x を選択)

例題コインで点が動く

数直線上の点が原点にある。コインを投げて表なら +2、裏なら −1 動く。5回投げたとき、点が 1 にある確率を求めよ。

試す実際に投げてみる
ヒント表の回数を x とおく

5回のうち表が x 回なら、裏は 5 − x 回。最後の位置は 2x − (5 − x) です。これが 1 になる x を求めれば、あとは反復試行の定理です。

解答解き方

答え:5/16

  1. 表が x 回とすると 2x − (5 − x) = 1 → 3x = 6 → x = 2。つまり「表がちょうど2回」。
  2. 反復試行の定理より 5C2(1/2)2(1/2)3 = 10/32 = 5/16。

上のシミュレーションで「1000セット」を何回か押すと、割合が 5/16 = 0.3125 に近づいていくのが分かります。

2.2条件付き確率

事象 A₁ が起こっているという条件のもとで A₂ が起こる確率を、A₁ のもとでの A₂ の条件付き確率といい、PA₁(A₂) または P(A₂ | A₁) と書きます。

P(A₂ | A₁) = P(A₁ ∩ A₂)P(A₁)ただし P(A₁) ≠ 0

「A₁ が起きた」と分かった時点で、考える世界(全体)が Ω から A₁ に縮むと考えると分かりやすいです。ページ上部の表で、A₁ を選ぶと薄い青に縮んだ世界が見えます。

例:サイコロ2個で「合計が8」と分かっているとき、1個目が偶数である確率。合計8は (2,6)(3,5)(4,4)(5,3)(6,2) の5通り、そのうち1個目が偶数は3通りなので 3/5。上の表で A₁=「合計が8」、A₂=「1個目が偶数」を選んで確かめてみましょう。

定理乗法定理

条件付き確率の式の分母を払うと、「両方起こる確率」を順番に掛け算で求める式になります。

P(A₁ ∩ A₂) = P(A₁) · P(A₂ | A₁) = P(A₂) · P(A₁ | A₂)

A₁ ∩ A₂ は A₂ ∩ A₁ と同じなので、どちらから見ても同じ値です。つまり

P(A₁) · P(A₂ | A₁) = P(A₂) · P(A₁ | A₂)これが乗法定理(後で習うベイズの定理のもとになる式)
独立との関係:A₁ と A₂ が独立なら、A₁ が起きても A₂ の確率は変わらないので P(A₂ | A₁) = P(A₂)。これを乗法定理に入れると 2.1 の P(A₁ ∩ A₂) = P(A₁)P(A₂) になります。

例:赤玉3個・白玉2個の袋から、戻さずに2個取り出す

1個目2個目確率 赤 3/5赤 2/43/5 × 2/4 = 6/20 白 2/43/5 × 2/4 = 6/20 白 2/5赤 3/42/5 × 3/4 = 6/20 白 1/42/5 × 1/4 = 2/20

2個目の確率(青字)が1個目の結果で変わっているのがポイントです。これが P(A₂ | A₁)。4つの合計は 20/20 = 1 になります。

Q練習問題

答えを分数(例 3/5)か小数で入力して「判定」を押してください。約分していなくても正解になります。

問1 独立な試行

サイコロを2回投げる。1回目が偶数で、かつ2回目が5以上である確率は?

答え答えと解説

答え:1/6

独立なので掛け算。3/6 × 2/6 = 1/2 × 1/3 = 1/6。

問2 反復試行

コインを4回投げて、表がちょうど3回出る確率は?

答え答えと解説

答え:1/4

4C3(1/2)3(1/2)1 = 4/16 = 1/4。

問3 少なくとも1回

サイコロを4回投げて、6の目が少なくとも1回出る確率は?

答え答えと解説

答え:671/1296

「少なくとも1回」は余事象「1回も出ない」を使うのが楽です。1回も出ない確率は (5/6)4 = 625/1296。よって 1 − 625/1296 = 671/1296(約 0.518)。

1回〜4回の場合を全部足しても同じ答えになりますが、計算が4倍になります。

問4 点の移動

例題と同じルール(表で +2、裏で −1)でコインを6回投げる。点が 3 にある確率は?

答え答えと解説

答え:5/16

表 x 回で 2x − (6 − x) = 3 → x = 3。6C3(1/2)6 = 20/64 = 5/16。

問5 当たりくじ

当たる確率が 1/10 のくじを、毎回もとに戻して4回引く。ちょうど1回だけ当たる確率は?

答え答えと解説

答え:729/2500

4C1(1/10)1(9/10)3 = 4 × 729/10000 = 2916/10000 = 729/2500(約 0.29)。

「もとに戻す」ので毎回の確率は同じ 1/10 = 独立な試行です。

問6 条件付き確率

サイコロを2個投げたところ、目の合計が 8 だった。1個目の目が偶数である確率は?

答え答えと解説

答え:3/5

合計8は5通り。そのうち1個目が偶数は (2,6)(4,4)(6,2) の3通り。式で書くと P(A₂|A₁) = (3/36)/(5/36) = 3/5。ページ上部の表でも確かめられます。

問7 乗法定理

赤玉3個・白玉2個の袋から、戻さずに2個取り出す。2個とも赤である確率は?

答え答えと解説

答え:3/10

P(1個目赤) × P(2個目赤 | 1個目赤) = 3/5 × 2/4 = 3/10。

問8 2個目が赤

問7と同じ袋で、2個目が赤である確率は?

答え答えと解説

答え:3/5

1個目が赤の場合と白の場合に分けて足します。3/5 × 2/4 + 2/5 × 3/4 = 6/20 + 6/20 = 3/5。

1個目と同じ 3/5 になります。1個目を見ていなければ、2個目も「5個のうち赤3個」から選ぶのと同じだからです(くじ引きの順番は公平)。

問9 逆向きの条件付き確率

問7と同じ袋で、2個目が赤だったと分かった。このとき1個目も赤だった確率は?

答え答えと解説

答え:1/2

乗法定理 P(A₂)·P(A₁|A₂) = P(A₁ ∩ A₂) より P(A₁|A₂) = (3/10) ÷ (3/5) = 1/2。

「後の結果から前の結果を推測する」この考え方がベイズの定理につながります。

問10 独立かどうか

サイコロを1個投げる。A=「偶数の目」、B=「4以下の目」とする。A と B は独立か?(P(A∩B) と P(A)P(B) を比べてみよう)

答え答えと解説

答え:独立である

A∩B = {2, 4} なので P(A∩B) = 2/6 = 1/3。P(A)P(B) = 1/2 × 4/6 = 1/3。等しいので独立です。

「B=4以下」と分かっても偶数の割合は {1,2,3,4} のうち2個で 1/2 のまま、つまり P(A|B) = P(A) です。B を「3以下」に変えると 1/6 ≠ 1/4 で独立ではなくなります。1回の試行の中の事象でも独立になることがある、という例です。

数値はすべて計算で確認済みです。シミュレーションは乱数を使うため、押すたびに少しずつ結果が変わります。
