確率の考え方と確率空間

確率統計 第2回のノートのまとめです。「確率」にはいくつかの考え方があること、そして数学ではそれを (Ω, 𝓕, P) という3点セットで定義することを、動かしながら確かめます。

1確率の種類

「確率」という言葉には、大きく分けて2つの立場があります。

確率
客観的確率数学的確率(理論的確率)場合の数の比で決まる。
客観的確率統計的確率(経験的確率)たくさん試した結果の割合で決まる。
主観的確率主観的確率その人がどれくらい確信しているかの度合い。

1.1数学的確率(理論的確率)

P(A) = |A||Ω||A|:A が起こる場合の数 |Ω|:起こりうるすべての場合の数(どれも同様に確からしい)
試すサイコロの目をタップして事象 A を作る

何も選ばない A = ∅ なら P = 0、全部選んで A = Ω なら P = 1。どんな A でも 0 ≤ P(A) ≤ 1 になることが見て取れます。これが後で出てくる確率の定義(公理)の元になっています。

1.2統計的確率(経験的確率)

試行を m 回行い、事象 A が r 回起こったとします。m を大きくしていったときの割合 r/m の行き着く値 p を、A の統計的確率とします。

P(A) = limm→∞ rm = p

ページ上部のグラフで「+1000回」を何度か押すと、最初はばらついていた折れ線が理論値の線に近づいていきます(大数の法則)。画びょうの向きのように、場合の数で計算できないものでも、この方法なら確率を決められます。

1.3主観的確率

「明日の試験に受かる気が 80% くらいする」のような、個人の確信の度合いを数値にしたものです。同じ出来事でも人によって値が違ってかまいません。くり返せない1回きりの出来事にも使えます。

2確率の定義 ① σ集合体(完全加法族)

数学的確率も統計的確率も、共通して満たすルールだけを取り出して「確率」を定義します。まず、確率を考えてよい事象の集まりを決めます。

標本空間 Ω の部分集合からなる集合族 𝓕 が、次の3つの条件を満たすとき、𝓕 を σ集合体(完全加法族)とよびます。

条件意味(ことばで)
(i) Ω ∈ 𝓕「何かが起こる」という事象は入っている
(ii) A ∈ 𝓕 ⇒ Ac ∈ 𝓕A が入っていれば「A が起こらない」も入っている
(iii) Ai ∈ 𝓕 (i=1,2,…) ⇒ ⋃Ai ∈ 𝓕入っている事象の「または」も入っている

𝓕 の要素を事象とよび、Ω と 𝓕 の組 (Ω, 𝓕) を可測空間といいます。

ノートの例:コイン1枚なら Ω = {H, T}、𝓕 = {∅, {H}, {T}, {H, T}}。Ω の部分集合を全部集めたもの(べき集合)は必ず σ集合体になります。
試すσ集合体チェッカー

部分集合をタップして 𝓕 に入れたり外したりしてください。

Ω が有限集合なら、(iii) は「2つずつの和集合が入っているか」を確かめれば十分です。また (i) と (ii) から Ωc = ∅ も必ず入ります。

3確率の定義 ② 確率測度と確率空間

σ集合体 𝓕 上で定義された関数 P が、次の3つを満たすとき、P を Ω の確率測度といいます。

公理意味
(1) P(Ω) = 1全体の確率は1
(2) 0 ≤ P(A) ≤ 1 (A ∈ 𝓕)どの事象の確率も0以上1以下
(3) Ai ∩ Aj = ∅ (i ≠ j) のとき
P(⋃Ai) = ΣP(Ai)		重ならない事象の「または」の確率は、足し算

そして Ω、𝓕、P の3つを組にした (Ω, 𝓕, P) を確率空間とよびます。

試すΩ = {1, 2, 3} に確率を配ってみる

根元事象 {1}, {2}, {3} の確率を決めると、公理(3)の足し算で、残りの事象の確率がすべて決まります。

Q練習問題

数値の問題は分数(例 3/4)か小数で入力して「判定」を押してください。

問1 確率の種類

次の確率は、数学的・統計的・主観的のどれにあたるか。

  1. サイコロで1の目が出る確率は 1/6
  2. 過去のデータから、この地域の6月に雨が降る確率は 40%
  3. 自分が次の試験で満点を取る確率は 10% くらいだと思う
答え答えと解説

答え:数学的・統計的・主観的

  1. 数学的確率:6通りが同様に確からしいとして、場合の数の比で決めている。
  2. 統計的確率:実際に起こった回数の割合から決めている。
  3. 主観的確率:個人の確信の度合い。
問2 数学的確率

ジョーカーを除くトランプ52枚から1枚引くとき、ハートである確率は?

答え答えと解説

答え:1/4

|A|/|Ω| = 13/52 = 1/4。

問3 標本空間

コインを2枚投げる。標本空間 Ω を書き出したうえで、少なくとも1枚が表(H)である確率を求めよ。

答え答えと解説

答え:3/4

Ω = {HH, HT, TH, TT}(4通り)。少なくとも1枚表は TT 以外の3通りなので 3/4。

「表0枚・1枚・2枚」の3通りを Ω にすると、それぞれの起こりやすさが同じでないので数学的確率の式が使えません(1枚は HT と TH の2通り分)。

問4 統計的確率

画びょうを1000回投げたら、針が上を向いたのが620回だった。針が上を向く統計的確率(の推定値)は?

答え答えと解説

答え:0.62

r/m = 620/1000 = 0.62。画びょうは形が非対称なので「同様に確からしい」が使えず、数学的確率では求められません。

問5 σ集合体かどうか

Ω = {1, 2, 3} とする。次の 𝓕 は σ集合体か。

  1. 𝓕 = {∅, {1}, {2, 3}, {1, 2, 3}}
  2. 𝓕 = {∅, {1}, {1, 2, 3}}
  3. 𝓕 = {∅, {1}, {2}, {2, 3}, {1, 3}, {1, 2, 3}}
答え答えと解説

答え:1は〇、2と3は✕

  1. 〇。{1} と {2,3} が互いに補集合、∅ と Ω も補集合。和集合もすべて中にある。
  2. ✕。{1} の補集合 {2, 3} が入っていないので (ii) を満たさない。
  3. ✕。補集合はそろっているが、{1} ∪ {2} = {1, 2} が入っていないので (iii) を満たさない。

上のチェッカーで同じ 𝓕 を作ると確かめられます。「足りないものを補って完成させる」を押すと、2は1と同じ形に、3はべき集合(8個)になります。

問6 べき集合の大きさ

Ω = {1, 2, 3} の部分集合をすべて集めた 𝓕(べき集合)の要素はいくつか。

答え答えと解説

答え:8

各要素について「入れる/入れない」の2通りなので 23 = 8。Ω = {H, T} なら 22 = 4 で、ノートの例と一致します。

問7 公理を使った計算

Ω = {1, 2, 3} で P({1}) = 0.2、P({2}) = 0.5 とする。P({1, 3}) は?

答え答えと解説

答え:0.5

公理(1)と(3)より P({1}) + P({2}) + P({3}) = P(Ω) = 1 なので P({3}) = 0.3。{1} と {3} は重ならないので P({1, 3}) = 0.2 + 0.3 = 0.5。

別解:{1, 3} は {2} の補集合なので 1 − 0.5 = 0.5(次の問8)。

問8 公理から性質を導く

確率測度の公理 (1)〜(3) だけを使って、P(Ac) = 1 − P(A) を示せ。

答え答えと解説

答え:証明

  1. A と Ac は重ならない(A ∩ Ac = ∅)。また A ∪ Ac = Ω。
  2. 公理(3)より P(A ∪ Ac) = P(A) + P(Ac)。
  3. 左辺は P(Ω) なので、公理(1)より 1。よって P(A) + P(Ac) = 1、つまり P(Ac) = 1 − P(A)。

特に A = Ω とすると Ac = ∅ なので P(∅) = 0 も分かります。「少なくとも1回」の問題で余事象を使えるのは、この性質のおかげです。

シミュレーションは乱数を使うため、押すたびに結果が変わります。
