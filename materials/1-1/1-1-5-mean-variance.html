1前回の続き:確率密度関数と分布関数の例

f(x) = c(−1 ≤ x ≤ 1)、それ以外で 0 が確率密度関数になるように c を決め、分布関数 F(x) を求める。

確率密度関数であるためには、全体の面積が 1 でなければならない。

∫−∞∞ f(x) dx = ∫−11 c dx = 2c = 1  ∴ c = 1/2
F(x) = ∫−∞x f(t) dt = ∫−1x ½ dt = ½(x+1)(−1 ≤ x ≤ 1)
F(x) = { 0(x < −1)、 ½(x+1)(−1 ≤ x ≤ 1)、 1(x > 1)}
試すx を動かして F(x) = 塗った面積 を確かめる

2平均と分散 4.1 離散的な場合:平均(期待値)

確率変数 X(値 x1, …, xn)に対する平均、あるいは 期待値 は

μx = E[X] = Σi=1n xi・P(xi)値 × その確率 を全部足す

X2 の期待値なら、xi を xi2 に置き換えて E[X2] = Σ xi2・P(xi)。

例:サイコロの出る目の平均(期待値)

μx = 1×⅙ + 2×⅙ + … + 6×⅙ = 21/6 = 3.5

平均は、確率を「重さ」と考えたときの重心(つり合う点)。上のサイコロ実験室の ▲ がその位置です。

3計算表で確かめる

サイコロ実験室で選んだ分布について、平均と分散を表で計算します(小数第4位で四捨五入)。

4平均に関する公式

(1)E(aX + b) = aE(X) + b定数倍・定数の足し算はそのまま外に出せる
(2)E(X + Y) = E(X) + E(Y)X と Y が独立でなくてもいつでも成り立つ
(3)E(XY) = E(X)E(Y)X と Y が 独立 のときに成り立つ
(3) は X と Y が独立でないと成り立たない。下の「同時確率の表」で、独立でない例(Y = X など)を選ぶと E(XY) ≠ E(X)E(Y) になることを確かめられます。

5同時確率と (2) の証明

同時確率(結合確率)とは、複数の事象が同時に起こる確率のこと。X = xi かつ Y = yj となる確率を P(xi, yj) と書く。

表の行や列ごとに足した値を 周辺和 といい、X だけの確率になる。

P(xi) = Σj=1m P(xi, yj)

証明:E[X ± Y] = E[X] ± E[Y]

E[X ± Y] = ΣiΣj (xi ± yj) P(xi, yj)
= Σi xi {Σj P(xi, yj)} ± Σj yj {Σi P(xi, yj)}
= Σi xi P(xi) ± Σj yj P(yj)  (周辺和)
= E[X] ± E[Y]
試す同時確率の表(X, Y はそれぞれ 1, 2, 3 の値をとる)

マスをタップすると重みが 1 増えます(9 の次は 0)。重みの割合が同時確率になります。

6分散と標準偏差

分散は、平均からのずれの2乗の期待値。ばらつきの大きさを表す。

σx2 = E[(X − μx)2] = Σi=1n (xi − μx)2 P(xi)

分散の正の平方根 σx を 標準偏差 という(元の値と同じ単位になる)。

例:サイコロの分散

σx2 = (1−3.5)2×⅙ + (2−3.5)2×⅙ + … + (6−3.5)2×⅙ = 8.75/3 = 35/12 ≒ 2.92
σx = √(35/12) ≒ 1.71

別の求め方:σ2 = E[X2] − (E[X])2。サイコロなら E[X2] = (1+4+9+16+25+36)/6 = 91/6 なので、91/6 − 3.52 = 91/6 − 49/4 = 35/12。計算が楽になることが多い。

7Y = aX + b にすると?

公式 (1) を確かめる。X は上のサイコロ実験室の分布。目を a 倍して b を足した Y = aX + b の平均と分散を、直接計算した値と公式の値で比べる。

平均はずらした分(b)だけ動くが、分散は b に関係なく a2 倍(全体をずらしてもばらつきは変わらない)。標準偏差は |a| 倍。

問7

答え:12.25(= 49/4)

独立なので E(XY) = E(X)E(Y) = 3.5 × 3.5 = 12.25。

問9
