2文・ブロック・コメント

  • 文(statement):処理の1単位。最後に セミコロン ; を付ける。x = 3; や printf("hi");
  • 式(expression):値を持つもの。3 + 4、x > 0、x = 3(代入も式)。式の後ろに ; を付けると文になる。
  • ブロック:{ } で囲んだ文のまとまり。if や for の中身、関数の本体になる。ブロックの後ろには ; を付けない。
  • コメント:/* 〜 */(複数行可)と // 〜(行末まで)。コンパイラは無視する。
  • インデント(字下げ):コンパイラは無視するが、ブロックの入れ子を人が読みやすくするために必ず付ける。
よくあるミス:if (x > 0); のように if の直後に ; を書くと、「何もしない文」が if の中身になり、次の { } は条件に関係なく必ず実行されます。

3識別子と予約語

識別子:変数や関数につける名前。次のルールがあります。

  • 使える文字は 英字(A〜Z, a〜z)、数字(0〜9)、アンダースコア(_)
  • 先頭に数字は使えない
  • 大文字と小文字は区別される(sum と Sum は別物)
  • 予約語(int, if, for, return など、C言語が使う単語)は使えない

4変数とデータ型

変数:値を入れておく、名前の付いたメモリ上の場所。使う前に型と名前を書いて用意する(宣言)。

int count;            /* 宣言(中身は不定) */
int sum = 0;          /* 宣言と同時に初期化 */
double ave = 0.0, rate = 1.5;   /* まとめて宣言できる */
char c = 'A';         /* 文字は ' ' で囲む */
型入れるもの大きさ(VS)printfscanf
char1文字(実体は小さな整数)1バイト%c%c
int整数4バイト%d%d
long long大きな整数8バイト%lld%lld
float実数(精度低)4バイト%f%f
double実数(精度高)8バイト%f%lf
注意:初期化していない変数の中身は「たまたまそこにあった値」(不定)です。合計を入れる変数などは必ず 0 で初期化しましょう。double を scanf で読むときだけは %lf です。
整数どうしの割り算:7 / 2 は 3(小数点以下切り捨て)。3.5 にしたいときは 7.0 / 2 か (double)7 / 2。修飾子や型の範囲は「演算子と型修飾子」の教材も見てください。

6入力と出力:printf と scanf

  • printf("書式", 値, …);:書式の中の 変換指定子(%d など)の位置に、後ろの値が順番に入る。\n は改行。
  • scanf("書式", &変数, …);:キーボードから読み込む。変数の前に &(アドレス)を付ける。ただし配列(文字列)には付けない。

7制御構造

プログラムは基本的に上から順に実行されます(順次)。それを変えるのが分岐と繰り返しです。

構文使いどころ形
if / else if / else条件で処理を分けるif (条件) { … } else { … }
switch1つの整数値で多方向に分けるswitch (x) { case 1: … break; default: … }
for回数が決まった繰り返しfor (初期化; 条件; 更新) { … }
while条件が成り立つ間くり返すwhile (条件) { … }
do-while最低1回は実行してから判定do { … } while (条件);
  • break:switch や繰り返しをその場で抜ける。continue:繰り返しの残りを飛ばして次の回へ。
  • switch の case の最後に break を忘れると、下の case まで続けて実行される(フォールスルー)。

8関数:宣言と定義

関数:処理をまとめて名前を付けたもの。main も関数の1つで、プログラムは必ず main から始まります。

#include <stdio.h>

int square(int x);          /* 関数の宣言(プロトタイプ) */

int main(void)
{
    int a = square(5);      /* 関数の呼び出し → 25 が返る */
    printf("%d\n", a);
    return 0;
}

int square(int x)           /* 関数の定義 */
{
    return x * x;           /* 呼び出し元に値を返す */
}
用語意味
宣言「こういう名前・型のものがある」とコンパイラに知らせること。関数ならプロトタイプ int square(int x);
定義実体を作ること。関数なら本体 { } まで書く。変数なら実際にメモリを確保する(int a; は宣言であり定義でもある)
引数(ひきすう)関数に渡す値。上の x
戻り値return で返す値。返さない関数の型は void

定義が main より後ろにある関数を main で使うときは、先に宣言(プロトタイプ)を書きます。printf の宣言は stdio.h の中に書いてあるので、#include <stdio.h> が必要です。

9配列と文字列

int score[5] = {80, 65, 90, 70, 55};   /* score[0] 〜 score[4] */
char name[10] = "Taro";                 /* 'T' 'a' 'r' 'o' '\0' */
  • 配列:同じ型の変数を並べたもの。添字は 0 から始まり、要素数 − 1 まで。範囲外を使ってもエラーにならず、おかしな動作をするので注意。
  • 文字列:char の配列で、最後に終わりの印 '\0' が入る。"Taro" は4文字だが5バイト必要。
  • 文字列の比較は == ではできない。string.h の strcmp(a, b) を使い、同じなら 0 が返る(課題2-3 第3段階で使います)。
