1たくさんの値の扱い ― 配列(第7章)

  • 単一の変数:1つの値しか保持できない。
  • 配列:複数の同じ型の変数を1つにまとめたもの。
  • 例:クラス全員のテストの点数を保持したい → 変数を tensu_A, tensu_B, …, tensu_Z と人数分作るのは大変。配列なら int tensu[N]; の1行で N 人分。

2配列の宣言と要素

int a[10];型 配列名[要素数]; → int 型の変数が 10 個用意される
  • 宣言した型の変数が、要素数の分だけ連続してメモリに取られる(int が 4 バイトなら、アドレスが 4 ずつ並ぶ)。
  • N 個の要素には、0 番を先頭に 0, 1, 2, …, N−1 と番号(要素番号、添字)が付く。「配列名[要素番号]」で使う。
  • 1番目は a[0]、2番目は a[1]、…、10番目は a[9]。最後の要素番号は 要素数 − 1。
  • 各要素は普通の変数と同じように使える。a[2] = 10; は「3番目の要素に 10 を代入」。scanf で入力するときは &a[2] と & を付ける。
a[10] のように範囲外の番号を使っても、C ではエラーにならずに動いてしまうことがあり、ほかの変数を壊したり異常終了したりする。上のメモリ図で a[5] や a[-1] に代入してみよう。

3配列の初期化

宣言と同時に { } で各要素の初期値を代入できる。

書き方結果
int a[5] = {1, 2, 3, 4, 5};5 個すべてに値が入る
int a[5] = {1, 2, 3, 4, 5, 6};要素は5個なのに初期値が6個 → 通常コンパイラがエラー(警告)を出す
int a[5] = {1, 2};初期値が足りない要素には 0 が入る → 1, 2, 0, 0, 0
int a[] = {10, 20, 30};[ ] 内の要素数は省略できる。初期値の数から要素数 3 になる(int a[3] = {10, 20, 30}; と同じ)

上のメモリ図で、要素数を空欄にしたり、初期値の数を増やしたり減らしたりして確かめられます。int a[100] = {0}; と書けば全部 0 にできる。

4配列の使い方:for 文と組み合わせる

  • 5つの値を表示するとき、個別の変数(suti1〜suti5)だと printf を5回書く必要がある。
  • 配列なら、要素番号に for 文のカウンター変数 i を使って hairetu[i] と書ける → 反復処理を簡素に書けるのが配列のメリット。
  • キーボードからの入力も、合計の計算も同じように for 文で書ける。

例:5人の点数を入力して合計と平均を出す

#include <stdio.h>
#define N 5

int main(void)
{
    int tensu[N];           /* 5 人分の点数 */
    int i, goukei = 0;

    for (i = 0; i < N; i++) {           /* i は 0, 1, 2, 3, 4 */
        printf("%d 人目の点数: ", i + 1);
        scanf("%d", &tensu[i]);         /* 要素にも & を付ける */
    }
    for (i = 0; i < N; i++) {
        goukei += tensu[i];
    }
    printf("合計 %d 点、平均 %.1f 点\n", goukei, (double)goukei / N);
    return 0;
}
1 人目の点数: 70 2 人目の点数: 80 3 人目の点数: 65 4 人目の点数: 90 5 人目の点数: 100 合計 405 点、平均 81.0 点

#define N 5 にしておくと、人数を変えるときに1か所直すだけで済む。for の条件は i < N(i <= N にすると範囲外の tensu[5] を使ってしまう)。

5多次元配列

  • 1次元配列を2次元、3次元に拡張した配列。int a[2][3]; は「2行3列」の表のようなもの。
  • 初期化は、次元の数だけ { } が入れ子になる。{ } やカンマの組み合わせに注意。
int a[2][3] = { {10, 20, 30}, {40, 50, 60} };
試すマスをタップすると、その要素の書き方が出ます
マスをタップしてみよう
#include <stdio.h>

int main(void)
{
    int a[2][3] = { {10, 20, 30},
                    {40, 50, 60} };     /* 2 行 3 列 */
    int i, j;

    a[1][2] = 99;                       /* 2 行目・3 列目を書き換え */
    for (i = 0; i < 2; i++) {           /* 行 */
        for (j = 0; j < 3; j++) {       /* 列 */
            printf("%4d", a[i][j]);
        }
        printf("\n");
    }
    return 0;
}
10 20 30 40 50 99

2重の for 文で、外側が行(i)、内側が列(j)。

6文字列の扱い ― 文字配列(第8章)

  • C には「文字列型」がない。文字列は char 型の配列(文字配列)に1文字ずつ入れる。
  • 文字列の終わりには、目印として ヌル文字('\0'、値は 0)を置く。printf の %s などは、ヌル文字を見て「ここで終わり」と判断する。
  • 終了コード(ヌル文字)がないと、文字列の終わりが判定できない。要注意!
  • "ringo" は 5 文字だが、ヌル文字を入れて 6 要素が必要。

7文字配列の初期化

書き方説明
char s[6] = "ringo";文字列リテラルで初期化。'\0' は自動で付く
char s[6] = {'r','i','n','g','o','\0'};文字並びで初期化。必ずヌル文字で終端すること。どちらも同じ結果
char s[] = "ringo";要素数を省略 → 文字数 + 1 = 6 が自動で取られる。ただし実行中にそれより長い文字列を入れないこと
char s[5] = {'x','x','x','x','\0'};特定の文字で埋める例
char s[10];初期化しないと中身は処理系依存(何が入っているか分からない)。ヌル文字で終わっていないと異常終了の原因に → 少なくとも char s[10] = ""; や {0} で初期化しておく
  • 配列が足りない例:char s[3] = "ringo"; → 入りきらない。
  • メモリを無駄にする例:char s[1000] = "ringo";
  • → 文字配列は「入れる文字数の最大 +1(ヌル文字)」で定義するのがベスト。
  • 隣り合った文字列リテラルは自動で1つにつながる:"ab" "cd" は "abcd" と同じ(あまり使わない)。
#include <stdio.h>

int main(void)
{
    char s1[] = "ringo";                          /* 文字列リテラルで初期化 */
    char s2[] = {'k', 'a', 'k', 'i', '\0'};       /* 文字並びで初期化(\0 を忘れずに) */
    int i;

    printf("%s\n", s1);                 /* %s:\0 の手前までまとめて表示 */

    for (i = 0; s2[i] != '\0'; i++) {   /* %c:1 文字ずつ、\0 が来たら終わり */
        printf("%c", s2[i]);
    }
    printf("\n");

    s1[0] = 'R';                        /* 一部の置き換えはできる */
    printf("%s(要素数 %d = 5 文字 + \\0)\n", s1, (int)sizeof s1);
    return 0;
}
ringo kaki Ringo(要素数 6 = 5 文字 + \0)

8文字列の表示と入力

書き方ポイント
まとめて表示printf("%s", s);%s に配列の名前を渡す。ヌル文字の手前まで表示
1文字ずつ表示printf("%c", s[i]);%c に1つの要素を渡す。for で s[i] != '\0' の間くり返す
入力scanf("%s", s);配列の名前には & を付けない。空白文字までしか読み込めない。'\0' は自動で追加される

%s と %c のループ、どちらが簡素? → %s の方が短く書ける。1文字ずつ処理したい(数える、置き換える)ときは %c とループ。

#include <stdio.h>
#include <string.h>

int main(void)
{
    char name[16];

    printf("名前(ローマ字): ");
    scanf("%15s", name);                /* & は付けない。15 文字まで(+\0 で 16) */
    printf("こんにちは、%s さん(%d 文字)\n", name, (int)strlen(name));

    /* name = "taro";  ← 配列に = で文字列は代入できない(コンパイルエラー) */
    strcpy(name, "taro");               /* 代入したいときは strcpy を使う */
    printf("%s\n", name);
    return 0;
}
名前(ローマ字): Hanako Yamada こんにちは、Hanako さん(6 文字) taro

「Hanako Yamada」と入力しても、空白の手前の Hanako しか読まれない。%15s は「最大15文字まで」で、配列があふれるのを防ぐ。

9文字列の代入と置き換え

  • 初期化のとき以外は、文字配列に文字列を = でそのまま代入できない。s = "kaki"; はコンパイルエラー。
  • 1文字ずつ代入する(s[0] = 'k'; s[1] = 'a'; … s[4] = '\0';)か、string.h の strcpy(s, "kaki"); を使う。
  • 初期化した文字配列の一部は、実行中に1文字ずつ上書きできる(s[0] = 'R';)。要素番号は 0 から始まることに注意。
