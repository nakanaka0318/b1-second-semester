3-1コインを n 回振ったときの全パターン

コインを n 回振ったときに、表または裏が出るパターンをすべて表示するプログラムを作成せよ。n は最大 10 まで対応していればよい。n=4 の出力を、提出するソースコードの末尾に注釈として挿入せよ。

例) n=3 の時 通し番号, パターン 1, 裏裏裏 2, 裏裏表 3, 裏表裏 4, 裏表表 5, 表裏裏 6, 表裏表 7, 表表裏 8, 表表表
ヒント1全部で何通り?

コイン1枚なら 2 通り(=21)、2枚なら 4 通り(=22)、3枚なら 8 通り(=23)。n 枚なら 2n 通り。n=10 なら 1024 通り。

C には「べき乗の演算子」がない。2^n はべき乗ではなく XOR(排他的論理和)になるので注意。for 文で 2 を n 回掛けるか、1 << n(1 を n ビット左シフト)で作る。

ヒント2コインの表し方

コイン1枚を整数 1 つで表す。例:0 なら裏、1 なら表。コインは最大 10 枚なので、配列 int coin[10]; を使う(単一の変数×10個やビット列でもできる)。

出力例の順番(裏裏裏 → 裏裏表 → 裏表裏 …)は、裏を 0、表を 1 とした 2 進数 000, 001, 010, … の順になっている。

ヒント3ループの形
for (組み合わせ数の上限まで) {
    /* (処理1) 組み合わせを確定する */
    /* (処理2) 組み合わせを出力する */
}

処理1と処理2を別々に考えよう。

ヒント4(処理1)次の組み合わせの作り方

コイン配列の値を 2 進数と見て、1 ずつ足していく:0000 → 0001 → 0010 → 0011 → … → 1111。上の「+1」ボタンで動きを確かめよう。

  1. 一番右(coin[n−1])から見ていく。
  2. 1 だったら 0 にして、1つ左へ(繰り上がり)。
  3. 0 を見つけたら 1 にして終わり。

値を1つずつずらしていく方法はほかにもたくさんある(十人十色)。例:ループの番号 k を 2 進数に分解する方法(別解)。

ヒント5(処理2)出力の仕方
if (coin[j] == 1) printf("表");
else              printf("裏");

これを j = 0 〜 n−1 でくり返し、最後に改行。分からなければ前期の内容(if と for)を復習しよう。

解答例配列に 1 を足していく
#include <stdio.h>

int main(void)
{
    int coin[10] = {0};   /* coin[j] が 0 なら裏、1 なら表 */
    int n, total, k, j;

    printf("n = ");
    scanf("%d", &n);
    if (n < 1 || n > 10) {
        printf("n は 1〜10 で入力してください\n");
        return 1;
    }

    total = 1;
    for (j = 0; j < n; j++) {    /* 全パターン数 = 2 の n 乗 */
        total = total * 2;
    }

    printf("通し番号, パターン\n");
    for (k = 1; k <= total; k++) {
        /* (処理2) いまのパターンを表示 */
        printf("%d, ", k);
        for (j = 0; j < n; j++) {
            if (coin[j] == 1) printf("表");
            else              printf("裏");
        }
        printf("\n");

        /* (処理1) 次のパターンへ:2進数として 1 を足す */
        j = n - 1;                      /* 一番右(最後の桁)から */
        while (j >= 0 && coin[j] == 1) {
            coin[j] = 0;                /* 1 は 0 にして繰り上げる */
            j--;
        }
        if (j >= 0) coin[j] = 1;        /* 最初に見つかった 0 を 1 に */
    }
    return 0;
}

  1. int coin[10] = {0}; で全部 0(裏)から始める。最初のパターンは「裏裏裏裏」。
  2. 表示したあとで、配列を 2 進数とみて 1 を足す。右端から 1 を 0 にしながら左へ進み、最初の 0 を 1 にする。
  3. これを 2n 回くり返す。最後(表表表表)の後の +1 では全部 0 に戻るが、ループが終わるので問題ない。
別解ループ番号 k を2進数に分解
#include <stdio.h>

int main(void)
{
    int coin[10];
    int n, k, j;

    printf("n = ");
    scanf("%d", &n);
    if (n < 1 || n > 10) {
        printf("n は 1〜10 で入力してください\n");
        return 1;
    }

    printf("通し番号, パターン\n");
    for (k = 0; k < (1 << n); k++) {        /* 1 << n は 2 の n 乗 */
        /* k を 2 進数にして、各桁を配列に入れる(左端が最上位ビット) */
        for (j = 0; j < n; j++) {
            coin[j] = (k >> (n - 1 - j)) & 1;
        }
        printf("%d, ", k + 1);
        for (j = 0; j < n; j++) {
            printf("%s", coin[j] ? "表" : "裏");
        }
        printf("\n");
    }
    return 0;
}

k = 0, 1, 2, … , 2n−1 の各ビットが、そのままコインの表裏になる。(k >> (n - 1 - j)) & 1 は「k の左から j 番目のビット」を取り出す式(第1回のビット演算)。

例:n=3、k=5 のとき 5 = 101(2) → 表裏表(6番目)。通し番号は k+1。

「前のパターンを覚えておく」必要がないので、3-3 以降のようにパターンごとに調べる処理と組み合わせやすい。

3-2連続した表の最大数を付ける

課題3-1における出力の一行ごとに、連続した表の最大数を付加せよ。表表表表裏表表 の場合は 4。n=4 の出力を注釈として挿入せよ。

例) n=3 の時 通し番号, パターン, 連続表最大数 1, 裏裏裏, 0 2, 裏裏表, 1 3, 裏表裏, 1 4, 裏表表, 2 5, 表裏裏, 1 6, 表裏表, 1 7, 表表裏, 2 8, 表表表, 3
見るn を選ぶと全パターンと連続表の最大数(色付き=最長の連続)
ヒント12つの変数を使う

「いま何枚続いているか(現連続数)」と「これまでの最大(最大数)」を別々に持つ。現連続数は裏が出るとクリアされるので、最大数を別に覚えておく必要がある。

ヒント21枚ずつの処理
  • 表なら:現連続数を +1。それが最大数より大きければ最大数を更新。
  • 裏なら:現連続数を 0 に戻す。

例:表表裏表 → 現連続数 1, 2, 0, 1 → 最大数 2。

ヒント3リセットの位置

現連続数と最大数は、パターンごとに 0 に戻す(パターンのループの中、コインのループの前)。外に置くと前のパターンの値が残る。

解答例表示しながら数える
#include <stdio.h>

int main(void)
{
    int coin[10] = {0};
    int n, total, k, j;
    int run, maxrun;    /* 現在の連続数と、その最大値 */

    printf("n = ");
    scanf("%d", &n);
    if (n < 1 || n > 10) {
        printf("n は 1〜10 で入力してください\n");
        return 1;
    }
    total = 1 << n;

    printf("通し番号, パターン, 連続表最大数\n");
    for (k = 1; k <= total; k++) {
        printf("%d, ", k);
        run = 0;
        maxrun = 0;
        for (j = 0; j < n; j++) {
            if (coin[j] == 1) {
                printf("表");
                run++;                          /* 表が続いた */
                if (run > maxrun) maxrun = run; /* 最大を更新 */
            } else {
                printf("裏");
                run = 0;                        /* 裏で途切れたのでクリア */
            }
        }
        printf(", %d\n", maxrun);

        j = n - 1;                              /* 次のパターンへ(+1) */
        while (j >= 0 && coin[j] == 1) {
            coin[j] = 0;
            j--;
        }
        if (j >= 0) coin[j] = 1;
    }
    return 0;
}

3-1 の表示ループの中で、表を表示するときに run を増やし、裏のときに 0 に戻すだけ。最大数は ", %d\n" で行末に付ける。

注意よくある間違い
  • 最後にまとめて比べる:裏が出たときだけ最大数を更新すると、「裏表表」のように表で終わるパターンで最後の連続が数えられない。表のたびに比べれば安全。
  • 表の総数を数えてしまう:表表裏表 は表が 3 枚だが、連続の最大は 2。

3-3連続した表の最大数が m 回となる確率

コインを n 回振ったときに、連続した表の最大数が m 回となる確率を書き出せ。n=4 の出力を注釈として挿入せよ。

例) n=3 の時 m, m回連続で表となる確率 0, 12.5% 1, 50.0% 2, 25.0% 3, 12.5%
見る確率のグラフ(3-3・3-4・3-5 共通)
ちょうど m 回(3-3)m 回以上(3-4)20%(3-5)
ヒント1確率の求め方

どのパターンも同じ確率(1/2n)で出るので、確率 = (最大数が m だったパターンの数) ÷ (全パターン数)。

n=3 なら全 8 パターンのうち最大数 1 は 4 パターン → 4/8 = 50%。

ヒント2集計用の配列

最大数ごとに数える配列 int count[11] = {0}; を用意し、パターンごとに count[maxrun]++;。これだけで「m 回が何パターンあったか」がそろう。

最大数は 0〜n の n+1 通りなので、n=10 なら 11 個必要(10 個だと count[10] が範囲外)。

ヒント3% の表示と割り算
  • 整数同士の割り算は小数が切り捨てられる(4 / 8 は 0)。100.0 * count[m] / total のように実数を混ぜる。
  • printf で % 記号そのものを出すには %% と書く:printf("%d, %.1f%%\n", m, p);
解答例count 配列で集計
#include <stdio.h>

int main(void)
{
    int coin[10];
    int count[11] = {0};    /* count[m] : 連続表の最大数が m だったパターンの数 */
    int n, total, k, j, m, run, maxrun;

    printf("n = ");
    scanf("%d", &n);
    if (n < 1 || n > 10) {
        printf("n は 1〜10 で入力してください\n");
        return 1;
    }
    total = 1 << n;

    for (k = 0; k < total; k++) {
        for (j = 0; j < n; j++) {
            coin[j] = (k >> (n - 1 - j)) & 1;
        }
        run = 0;
        maxrun = 0;
        for (j = 0; j < n; j++) {
            if (coin[j] == 1) {
                run++;
                if (run > maxrun) maxrun = run;
            } else {
                run = 0;
            }
        }
        count[maxrun]++;        /* 集計 */
    }

    printf("m, m回連続で表となる確率\n");
    for (m = 0; m <= n; m++) {
        printf("%d, %.1f%%\n", m, 100.0 * count[m] / total);
    }
    return 0;
}

n=4 の出力

m, m回連続で表となる確率 0, 6.2% 1, 43.8% 2, 31.2% 3, 12.5% 4, 6.2%

表示は不要になったので、3-1 の別解(k を2進数に分解)でパターンを作り、3-2 と同じ方法で最大数を求めて count[maxrun]++。最後に m = 0〜n の確率を表示する。

6.2% について:n=4 で最大数 0 の確率は 1/16 = 6.25%。printf の %.1f はちょうど真ん中の値を偶数側に丸めることが多く(6.25 → 6.2、31.25 → 31.2)、四捨五入とは違う結果になる。どちらで書いても計算は合っている。

3-4連続した表の最大数が m 回以上の確率

コインを n 回振ったときに、連続した表の最大数が m 回以上の確率を書き出せ。n=4 の出力を注釈として挿入せよ。

例) n=3 の時 m, m回以上連続で表となる確率 0, 100.0% 1, 87.5% 2, 37.5% 3, 12.5%
ヒント13-3 の結果を足す

「m 回以上」= m 回 + (m+1) 回 + … + n 回。3-3 の count を m から n まで足せばよい。n=3、m=2 なら 25.0% + 12.5% = 37.5%。

m = 0 は必ず 100%(最大数は 0 以上なので)。

ヒント2後ろから足すと楽

count[n], count[n]+count[n−1], … と後ろから順に足していく(累積和)と、二重ループなしで全部の m の値が求まる。

解答例m ごとに足し合わせる
#include <stdio.h>

int main(void)
{
    int coin[10];
    int count[11] = {0};
    int n, total, k, j, m, run, maxrun, atleast;

    printf("n = ");
    scanf("%d", &n);
    if (n < 1 || n > 10) {
        printf("n は 1〜10 で入力してください\n");
        return 1;
    }
    total = 1 << n;

    for (k = 0; k < total; k++) {
        for (j = 0; j < n; j++) {
            coin[j] = (k >> (n - 1 - j)) & 1;
        }
        run = 0;
        maxrun = 0;
        for (j = 0; j < n; j++) {
            if (coin[j] == 1) {
                run++;
                if (run > maxrun) maxrun = run;
            } else {
                run = 0;
            }
        }
        count[maxrun]++;
    }

    printf("m, m回以上連続で表となる確率\n");
    for (m = 0; m <= n; m++) {
        atleast = 0;
        for (j = m; j <= n; j++) {      /* m 以上をすべて足す */
            atleast += count[j];
        }
        printf("%d, %.1f%%\n", m, 100.0 * atleast / total);
    }
    return 0;
}

n=4 の出力

m, m回以上連続で表となる確率 0, 100.0% 1, 93.8% 2, 50.0% 3, 18.8% 4, 6.2%
別解累積和(後ろから足し込む)
#include <stdio.h>

int main(void)
{
    int coin[10];
    int count[12] = {0};    /* count[n+1] = 0 を番兵として使うため 12 個 */
    int n, total, k, j, m, run, maxrun;

    printf("n = ");
    scanf("%d", &n);
    if (n < 1 || n > 10) {
        printf("n は 1〜10 で入力してください\n");
        return 1;
    }
    total = 1 << n;

    for (k = 0; k < total; k++) {
        for (j = 0; j < n; j++) {
            coin[j] = (k >> (n - 1 - j)) & 1;
        }
        run = 0;
        maxrun = 0;
        for (j = 0; j < n; j++) {
            run = coin[j] ? run + 1 : 0;
            if (run > maxrun) maxrun = run;
        }
        count[maxrun]++;
    }

    /* 後ろから足し込むと、count[m] が「m 以上」の数になる(累積和) */
    for (m = n - 1; m >= 0; m--) {
        count[m] += count[m + 1];
    }

    printf("m, m回以上連続で表となる確率\n");
    for (m = 0; m <= n; m++) {
        printf("%d, %.1f%%\n", m, 100.0 * count[m] / total);
    }
    return 0;
}

count[m] += count[m + 1]; を m = n−1 から 0 へ向かって行うと、count[m] が「m 回以上のパターン数」に置き換わる。run = coin[j] ? run + 1 : 0; は if 〜 else を1行で書いた条件演算子。

3-5m 回以上の確率が 20% 以上となる最大の m

コインを n 回振ったときに、連続した表の最大数が m 回以上の確率が 20% 以上となる最大の m(n=3 の場合は m=2)を、n=3〜10 に対して求めよ。答えを注釈として挿入せよ。

n,連続した表の最大数がm回以上の確率が20%以上となるmの最大値 3, 2 4, ?? … 10, ??
ヒント1n=3 で確かめる

3-4 の n=3 の結果:m=2 は 37.5%(20% 以上)、m=3 は 12.5%(20% 未満)。だから答えは 2。上のグラフで、オレンジの棒が赤い点線(20%)を超えている一番右の m を探せばよい。

ヒント2n のループを外側に

3-4 のプログラム全体を for (n = 3; n <= 10; n++) で囲む。そのとき count 配列は n ごとに 0 に戻す(前の n の集計が残らないように)。

ヒント320% の比べ方

確率は m が大きくなるほど小さくなるので、m を 0 から順に調べて「20% 以上」の最後の m を覚えておけばよい。

実数の誤差を避けるなら、count[m] / total >= 0.2 の代わりに両辺に 100×total を掛けて count[m] * 100 >= total * 20 と整数で比べる。

解答例n=3〜10 をまとめて計算
#include <stdio.h>

int main(void)
{
    int coin[10];
    int count[12];
    int n, total, k, j, m, run, maxrun, best;

    printf("n,連続した表の最大数がm回以上の確率が20%%以上となるmの最大値\n");
    for (n = 3; n <= 10; n++) {
        for (m = 0; m <= n + 1; m++) count[m] = 0;   /* n ごとに集計し直す */
        total = 1 << n;

        for (k = 0; k < total; k++) {
            for (j = 0; j < n; j++) {
                coin[j] = (k >> (n - 1 - j)) & 1;
            }
            run = 0;
            maxrun = 0;
            for (j = 0; j < n; j++) {
                run = coin[j] ? run + 1 : 0;
                if (run > maxrun) maxrun = run;
            }
            count[maxrun]++;
        }
        for (m = n - 1; m >= 0; m--) {               /* 「m 回以上」の数にする */
            count[m] += count[m + 1];
        }

        best = 0;
        for (m = 0; m <= n; m++) {
            if (count[m] * 100 >= total * 20) {      /* 確率 >= 20% を整数で比べる */
                best = m;
            }
        }
        printf("%d, %d\n", n, best);
    }
    return 0;
}

出力(注釈に入れる答え)

n,連続した表の最大数がm回以上の確率が20%以上となるmの最大値 3, 2 4, 2 5, 3 6, 3 7, 3 8, 3 9, 4 10, 4

n が増えても、20% 以上で起こる「連続表の最大数」はゆっくりしか増えない(n=10 でも 4)。長い連続が起こる確率は、だいたい n に比例して増えるが、長さが1増えるごとに半分になるため。

★5つの課題に共通するコツ

コツどの課題で
2n は 1 << n か掛け算のループで。2^n は XOR なので×3-1〜3-5
配列を2進数とみて +1 する(繰り上がり)/ k を2進数に分解する3-1
「現在の値」と「最大値」を別の変数で持つ。パターンごとに 0 に戻す3-2〜3-5
種類ごとの個数は配列で数える(count[x]++)。大きさは「とりうる値の数」3-3〜3-5
割合は 100.0 * で実数にしてから割る。% は %%3-3, 3-4
「以上」は後ろから足す累積和で3-4, 3-5
