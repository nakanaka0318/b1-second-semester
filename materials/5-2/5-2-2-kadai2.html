    2-1英語の序数の接尾辞をつける

    キーボードから数字を入力し、その数字に英語で序数を表す接尾辞(st, nd, rd, th)をつけて表示する。

    1 -> 1st ／ 3 -> 3rd ／ 4 -> 4th ／ 22 -> 22nd

    まずはルールを調べる

    見る1〜120 の接尾辞(色で分類)
    stndrdth

    色の並び方に注目。ほとんどは「一の位」で決まるのに、11〜13 と 111〜113 だけ灰色(th)になっています。

    ヒント1何で決まっている?

    表を見ると、接尾辞はほとんど一の位の数字で決まっています。一の位が 1 なら st、2 なら nd、3 なら rd、それ以外(0, 4〜9)なら th。

    ヒント2一の位の取り出し方

    整数を 10 で割った余りが一の位です。C では % 演算子を使います。

    n % 10      /* 123 % 10 → 3 */
    ヒント3例外がある!

    一の位だけで決めると、11 は「11st」、12 は「12nd」、13 は「13rd」になってしまいます。正しくは 11th, 12th, 13th。111〜113 も同じです。

    つまり下2桁が 11, 12, 13 のときは例外で th。下2桁は n % 100 で取り出せます。

    ヒント4判定の順番

    if 〜 else if は上から順に判定され、最初に当てはまったところだけ実行されます。だから例外を先に書くのがポイント。

    1. 下2桁が 11〜13 → th
    2. 一の位が 1 → st
    3. 一の位が 2 → nd
    4. 一の位が 3 → rd
    5. それ以外 → th

    「11〜13」は n % 100 >= 11 && n % 100 <= 13 と書きます(11 <= n % 100 <= 13 は C では意図通りに動きません)。

    ヒント5表示の仕方

    数字と接尾辞はくっつけて表示します。printf("%d -> %dst\n", n, n); のように、%d の直後に文字を書けば OK。

    解答例if 〜 else if で書く
    #include <stdio.h>

int main(void)
{
    int n;

    printf("数字を入力: ");
    scanf("%d", &n);

    if (n % 100 >= 11 && n % 100 <= 13) {   /* 11, 12, 13 で終わる数は例外 */
        printf("%d -> %dth\n", n, n);
    } else if (n % 10 == 1) {
        printf("%d -> %dst\n", n, n);
    } else if (n % 10 == 2) {
        printf("%d -> %dnd\n", n, n);
    } else if (n % 10 == 3) {
        printf("%d -> %drd\n", n, n);
    } else {
        printf("%d -> %dth\n", n, n);
    }
    return 0;
}

    実行例

    数字を入力: 112 112 -> 112th
    1. n % 100 が 11〜13 なら、一の位に関係なく th。これを最初に判定するのが一番大事なところ。
    2. それ以外は一の位 n % 10 で st / nd / rd を選び、残りは全部 th。
    3. 0 や 1000 も一の位が 0 なので th になります(0th, 1000th)。
    別解1switch で一の位を分ける
    #include <stdio.h>

int main(void)
{
    int n;
    char *suffix;

    printf("数字を入力: ");
    scanf("%d", &n);

    switch (n % 10) {
    case 1:  suffix = "st"; break;
    case 2:  suffix = "nd"; break;
    case 3:  suffix = "rd"; break;
    default: suffix = "th"; break;
    }
    if (n % 100 >= 11 && n % 100 <= 13) {
        suffix = "th";                       /* 例外を後から上書き */
    }
    printf("%d -> %d%s\n", n, n, suffix);
    return 0;
}

    一の位による分岐を switch で書き、接尾辞を変数 suffix(文字列)に入れておきます。例外(11〜13)は後から上書きしているので、順番を気にしなくてよくなります。printf が1回で済むのも利点です。

    char *suffix は「文字列を指す変数」です。ポインタはまだ習っていなければ、「文字列を入れておける変数」と思っておけば大丈夫です。

    別解2配列で表を引く
    #include <stdio.h>

int main(void)
{
    const char *suf[4] = {"th", "st", "nd", "rd"};
    int n, k;

    printf("数字を入力: ");
    scanf("%d", &n);

    k = n % 10;
    if (k > 3 || (n % 100 >= 11 && n % 100 <= 13)) {
        k = 0;                               /* 0 番目 = "th" */
    }
    printf("%d -> %d%s\n", n, n, suf[k]);
    return 0;
}

    接尾辞を配列に並べておき、添字で選ぶ方法です。一の位 1〜3 はそのまま添字に使い、4 以上と 11〜13 は 0 番目("th")にします。if の数が減り、「データ」と「処理」を分けて書けます。

    注意よくある間違い
    • 例外を後に書く:if (n % 10 == 1) … else if (n % 100 == 11) だと、11 は先に st の条件に当てはまってしまい、例外の判定まで来ません。
    • n == 11 || n == 12 || n == 13 だけで判定:111, 112, 113 が 111st などになってしまいます。下2桁(% 100)で判定しましょう。
    • 負の数:C では -1 % 10 は -1 になるので、-1 は -1th と表示されます。気になる人は、負の数のときにエラーを表示するなどの工夫をしてみましょう(発展)。

    2-2入力された文字の種類を判定する

    キーボードから1文字を入力し、英大文字・英小文字・数字・それ以外のどれかを適切に表示する。

    半角英数字が入力されました。入力された文字は英大文字です。 半角英数字が入力されました。入力された文字は英小文字です。 半角英数字が入力されました。入力された文字は数字です。 半角英数字以外が入力されました。
    試す1文字入れると、文字コードと判定が出ます
    ヒント1文字は「数」

    課題1で学んだように、char の中身は文字コード(整数)です。ASCII では次のように連続して並んでいます。

    種類範囲文字コード(10進)
    数字'0' 〜 '9'48 〜 57
    英大文字'A' 〜 'Z'65 〜 90
    英小文字'a' 〜 'z'97 〜 122
    ヒント21文字の読み込み方
    char c;
scanf(" %c", &c);     /* %c の前の空白で、改行や空白を読み飛ばす */

    c = getchar(); でも1文字読めます(この場合 c は int 型にします)。

    ヒント3範囲の判定

    「c が 'A' 以上かつ 'Z' 以下」を C で書くと c >= 'A' && c <= 'Z'。65 や 90 と数字で書くより、意味が分かりやすくなります。

    ヒント44つに分ける

    if → else if → else if → else の形で、大文字・小文字・数字・それ以外の4つに分けます。最後の else が「どれにも当てはまらなかった場合」です。

    解答例文字コードの範囲で判定
    #include <stdio.h>

int main(void)
{
    char c;

    printf("1文字入力: ");
    scanf(" %c", &c);

    if (c >= 'A' && c <= 'Z') {
        printf("半角英数字が入力されました。入力された文字は英大文字です。\n");
    } else if (c >= 'a' && c <= 'z') {
        printf("半角英数字が入力されました。入力された文字は英小文字です。\n");
    } else if (c >= '0' && c <= '9') {
        printf("半角英数字が入力されました。入力された文字は数字です。\n");
    } else {
        printf("半角英数字以外が入力されました。\n");
    }
    return 0;
}

    実行例

    1文字入力: Q 半角英数字が入力されました。入力された文字は英大文字です。
    1. scanf(" %c", &c) で1文字読み込む。
    2. 大文字・小文字・数字の範囲を順に調べ、どれにも当てはまらなければ「以外」。
    3. 全角の「あ」などは1文字が複数バイトなので、最初の1バイトだけが読まれ、どの範囲にも入らず「以外」になります。
    別解1ctype.h の関数を使う
    #include <stdio.h>
#include <ctype.h>

int main(void)
{
    int c;

    printf("1文字入力: ");
    c = getchar();

    if (isupper(c)) {
        printf("半角英数字が入力されました。入力された文字は英大文字です。\n");
    } else if (islower(c)) {
        printf("半角英数字が入力されました。入力された文字は英小文字です。\n");
    } else if (isdigit(c)) {
        printf("半角英数字が入力されました。入力された文字は数字です。\n");
    } else {
        printf("半角英数字以外が入力されました。\n");
    }
    return 0;
}

    ctype.h には文字の種類を調べる関数がそろっています。isupper(大文字?)、islower(小文字?)、isdigit(数字?)は、当てはまると 0 以外を返します。他に isalpha(英字?)、isalnum(英数字?)もあります。

    課題の狙いが「文字コードの範囲を自分で書けるか」なら解答例の方、実際のプログラムなら別解の方がよく使われます。

    別解2判定と表示を分ける
    #include <stdio.h>

int main(void)
{
    char c;
    char *kind = NULL;

    printf("1文字入力: ");
    scanf(" %c", &c);

    if (c >= 'A' && c <= 'Z')      kind = "英大文字";
    else if (c >= 'a' && c <= 'z') kind = "英小文字";
    else if (c >= '0' && c <= '9') kind = "数字";

    if (kind != NULL) {
        printf("半角英数字が入力されました。入力された文字は%sです。\n", kind);
    } else {
        printf("半角英数字以外が入力されました。\n");
    }
    return 0;
}

    判定の結果(種類の名前)を変数 kind に入れ、表示は最後にまとめて行います。メッセージの共通部分「半角英数字が入力されました。」を1か所に書けるので、文言を直すときに楽です。NULL は「まだ何も入っていない」印です。

    注意よくある間違い
    • 'A' <= c <= 'Z':数学の書き方は C では使えません(常に真になる)。
    • c >= A:クォート ' ' を忘れると、A という変数だと思われてエラーになります。
    • c >= "A":" " は文字列なので別物です。1文字は ' ' で囲みます。
    • scanf("%c", c):& を忘れると実行時におかしくなります。

    2-3暗証番号を3回まで入力させる

    数字を入力し、暗証番号と一致すれば「正しい暗証番号が入力されました。」と表示して終了。間違えると「暗証番号が正しく入力されませんでした。」と表示して、3回まで入力をくり返す。

    第1段階:決めた暗証番号を表示して入力を受け付ける/第2段階:暗証番号もキーボードから設定する/第3段階:最初の数字が「0」でも対応する

    試す暗証番号シミュレータ(第2・第3段階の違い)
    「0123」を設定して「123」を入れてみよう。int の比べ方では…?
    ヒント1「3回まで」の繰り返し

    回数が決まった繰り返しなので for 文が使えます。

    for (i = 1; i <= 3; i++) {
    /* 入力して、正しいか調べる */
}
    ヒント2正しかったら途中で終わる

    正しい番号が入ったら、残りの回数は不要です。方法は3つ:

    • return 0; でプログラム(main)を終了する
    • break; でループだけ抜ける
    • 「正解したか」を表す変数(フラグ)を作り、ループの条件に入れる
    ヒント3第1段階:暗証番号を決めておく

    int pin = 1234; のように変数に入れておき、テスト用に最初に表示します。入力を input に読み込み、input == pin で比べます(= 1つは代入なので注意)。

    ヒント4第2段階:暗証番号も入力する

    ループの前に、scanf("%d", &pin); で暗証番号を設定させれば OK。ループの中に書くと毎回設定し直すことになってしまいます。

    ヒント5第3段階:「0」で始まると何が困る?

    int で読み込むと、「0123」は数として 123 になります。先頭の 0 の情報が消えるので、「123」と入力しても正解になってしまいます(上のシミュレータで試せます)。

    対策:暗証番号を数ではなく文字列として扱い、char pin[16]; に scanf("%15s", pin); で読み込みます。文字列の比較は == ではなく strcmp(string.h)を使い、同じなら 0 が返ります。

    解答例第1段階
    #include <stdio.h>

int main(void)
{
    int pin = 1234;      /* あらかじめ決めた暗証番号 */
    int input, i;

    printf("(テスト用)暗証番号は %d です。\n", pin);

    for (i = 1; i <= 3; i++) {
        printf("暗証番号を入力(%d回目): ", i);
        scanf("%d", &input);
        if (input == pin) {
            printf("正しい暗証番号が入力されました。\n");
            return 0;                /* 終了 */
        }
        printf("暗証番号が正しく入力されませんでした。\n");
    }
    return 0;
}

    実行例

    (テスト用)暗証番号は 1234 です。 暗証番号を入力(1回目): 1111 暗証番号が正しく入力されませんでした。 暗証番号を入力(2回目): 1234 正しい暗証番号が入力されました。

    正解したら return 0; でその場で終了。3回とも間違えると、for が終わって最後の return 0 に進みます。

    解答例第2段階(フラグを使う)
    #include <stdio.h>

int main(void)
{
    int pin, input, i;
    int ok = 0;

    printf("暗証番号を設定してください: ");
    scanf("%d", &pin);

    for (i = 1; i <= 3 && !ok; i++) {
        printf("暗証番号を入力(%d回目): ", i);
        scanf("%d", &input);
        if (input == pin) {
            ok = 1;
        } else {
            printf("暗証番号が正しく入力されませんでした。\n");
        }
    }
    if (ok) {
        printf("正しい暗証番号が入力されました。\n");
    }
    return 0;
}

    正解したかどうかを変数 ok(0 か 1)で覚えておき、ループの条件 i <= 3 && !ok に入れています。!ok は「ok が 0 なら真」。こうすると return を途中に書かずに済み、ループの後で「最終的に正解したか」を使った処理(例:3回失敗したらロック)を追加しやすくなります。

    このままだと、暗証番号「0123」に「123」を入力しても正解になります。これを直すのが第3段階です。
    解答例第3段階(文字列で比べる)
    #include <stdio.h>
#include <string.h>

int main(void)
{
    char pin[16], input[16];
    int i;

    printf("暗証番号を設定してください: ");
    scanf("%15s", pin);

    for (i = 1; i <= 3; i++) {
        printf("暗証番号を入力(%d回目): ", i);
        scanf("%15s", input);
        if (strcmp(input, pin) == 0) {      /* 文字列として比べる */
            printf("正しい暗証番号が入力されました。\n");
            return 0;
        }
        printf("暗証番号が正しく入力されませんでした。\n");
    }
    return 0;
}

    実行例

    暗証番号を設定してください: 0123 暗証番号を入力(1回目): 123 暗証番号が正しく入力されませんでした。 暗証番号を入力(2回目): 0123 正しい暗証番号が入力されました。
    1. 暗証番号も入力も char の配列(文字列)として読む。"0123" は '0' '1' '2' '3' の4文字のまま保存される。
    2. %15s の 15 は「最大15文字まで」。配列の大きさ 16 から終わりの印 '\0' の分を引いた数で、長すぎる入力で配列があふれるのを防ぐ。
    3. strcmp(input, pin) == 0 で2つの文字列が同じか判定する。
    別解第3段階を int のまま解く(桁数も比べる)
    #include <stdio.h>

int main(void)
{
    int pin, input, i;
    int pinlen, inlen;       /* 入力された桁数 */
    int a, b;

    printf("暗証番号を設定してください: ");
    scanf("%n%d%n", &a, &pin, &b);
    pinlen = b - a;

    for (i = 1; i <= 3; i++) {
        printf("暗証番号を入力(%d回目): ", i);
        scanf(" %n%d%n", &a, &input, &b);
        inlen = b - a;
        if (input == pin && inlen == pinlen) {   /* 値も桁数も同じ */
            printf("正しい暗証番号が入力されました。\n");
            return 0;
        }
        printf("暗証番号が正しく入力されませんでした。\n");
    }
    return 0;
}

    scanf の %n は「ここまでに読んだ文字数」を記録する指定子です。数字を読む前後の文字数の差から、何桁で入力されたかが分かります。値と桁数の両方が同じときだけ正解にすれば、「0123」と「123」を区別できます。

    少し高度な方法なので、まずは文字列版を理解しましょう。「暗証番号は数ではなく文字の並び」と考える方が自然です(電話番号や郵便番号も同じ)。

    発展さらに良くするなら
    • 試行回数を #define MAX_TRY 3 にして、回数を変えやすくする。
    • 「あと◯回入力できます」と残り回数を表示する(MAX_TRY - i)。
    • 暗証番号に数字以外が含まれていたら設定し直させる(課題2-2の判定が使える)。
    • 3回失敗したら「ロックされました」と表示する(第2段階の ok フラグがあると簡単)。

    ★3つの課題に共通するコツ

    コツどの課題で
    if 〜 else if は上から順。例外・特別なケースを先に書く2-1
    範囲は a <= x && x <= b と && でつなぐ2-1, 2-2
    %(余り)で桁を取り出す:% 10 は一の位、% 100 は下2桁2-1
    文字は ' '、文字列は " "、文字列の比較は strcmp2-2, 2-3
    「何回か」の繰り返しは for、途中で抜けるなら return / break / フラグ2-3
    同じ文を何度も書くなら、変数(suffix, kind)にしてまとめる2-1, 2-2 の別解
    解答例と別解(全8本)はすべて gcc でコンパイルし、警告なしで動くこと、実行例どおりの出力になることを確認済みです。
