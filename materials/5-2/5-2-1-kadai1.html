課題1 解説
文字は「数」でできている

3つの課題はどれも、文字列を1文字ずつ見て、その文字コードを使う問題です。まずは下に何か打ち込んで、文字と番号・コードの関係を確かめてみてください。

上段 インデックス、中段 文字、下段 16進の文字コード。黄色は文頭以外の大文字(課題1-3で ^ を付ける位置)。

1-1文字・インデックス・文字コードを表示

キーボードから半角文字列を読み込んで配列に格納し、1文字ずつ次の3つを1行に表示する。

(1) 配列のインデックス (2) その文字 (3) その文字の文字コード(16進数)

押さえておくこと

C言語の文字列は char 型の配列で、最後に終わりの印 '\0' が入っています。Cat を読み込むと、配列の中身は次のようになります。

インデックス0123
中身'C''a''t''\0'

そして char の中身は実はただの整数(文字コード)です。同じ値でも、printf の書式を変えるだけで見え方が変わります。

書式表示'C' の場合
%c文字としてC
%d10進数として67
%x16進数として43
ヒント1文字列の読み込み方

char s[100]; のように配列を用意して、scanf("%s", s); で読み込みます。配列名 s はそれ自体がアドレスなので & は付けません。

入力が長すぎて配列からあふれないように、"%99s" と最大文字数を書いておくと安全です(最後の '\0' の分を1つ空けて 99)。

ヒント2いつまで繰り返す?

文字列の長さは入力によって変わります。for 文でインデックス i を 0 から増やしていき、s[i] が '\0' になったら止めるのがCの定番の書き方です。

1行の表示は、同じ s[i] を %c と %x の2回渡せばOKです。

解答例コードと解説
#include <stdio.h>

int main(void)
{
    char s[100];
    int i;

    printf("文字列を入力: ");
    scanf("%99s", s);

    for (i = 0; s[i] != '\0'; i++) {
        printf("%d, %c, %x\n", i, s[i], s[i]);
    }
    return 0;
}

実行例

文字列を入力: Cat 0, C, 43 1, a, 61 2, t, 74
  1. scanf("%99s", s) で文字列を配列 s に格納します。
  2. s[i] != '\0' の間だけループするので、入力の長さに関係なく全文字を処理できます。
  3. printf に s[i] を2回渡し、1回目は %c(文字)、2回目は %x(16進)で表示します。%X にすると 4A のように英字部分が大文字になります。
補足:%s は空白で読み込みが止まるので、Hello World と入れると Hello だけが処理されます。空白も含めたい場合は課題1-3の読み込み方を参照してください。

1-2すべて大文字にする

キーボードから英文字列を読み込んで、すべて大文字にして表示する。

例:Cat → CAT、dog → DOG

押さえておくこと

ASCIIコードでは、アルファベットは順番に並んでいて、小文字は大文字よりちょうど 32 大きい位置にあります。

大文字A = 65B = 66C = 67…Z = 90
小文字a = 97b = 98c = 99…z = 122

文字は整数なので、足し算や引き算、大小比較がそのままできます。たとえば 'a' - 32 は 'A' と同じ値です。

ヒント1何に 32 を引くか

すべての文字から 32 を引くと、もともと大文字の C(67)は 35 の # になってしまいます。小文字のときだけ引く必要があります。

ヒント2小文字かどうかの判定

小文字は 'a' から 'z' まで連続しているので、範囲で判定できます。

if (s[i] >= 'a' && s[i] <= 'z')

97 や 122 と数字で書くより、'a' と書いたほうが意味が読み取りやすくなります。

解答例コードと解説
#include <stdio.h>

int main(void)
{
    char s[100];
    int i;

    printf("英文字列を入力: ");
    scanf("%99s", s);

    for (i = 0; s[i] != '\0'; i++) {
        if (s[i] >= 'a' && s[i] <= 'z') {
            s[i] = s[i] - 32;   /* 小文字 → 大文字 */
        }
    }
    printf("%s\n", s);
    return 0;
}

実行例

英文字列を入力: Cat CAT
  1. 1-1 と同じく '\0' までループします。
  2. 小文字のときだけ 32 を引いて、配列の中身そのものを大文字に書き換えます。大文字や記号はそのまま残ります。
  3. 最後に %s で配列全体をまとめて表示します。
別解:s[i] - 32 の代わりに s[i] - ('a' - 'A') と書くと、32 という数字の意味がコードから分かります。また #include <ctype.h> の toupper(s[i]) を使えば判定ごと任せられますが、この課題の狙いは文字コードの差を使うことなので、まずは自分で書く方法を身につけましょう。

1-3文頭以外の大文字に ^ を付ける

半角の英文を読み込み、文頭以外で大文字が使われている位置を、次の行に ^ で示す。長い文への対策も考えるとなお良い。

This is a Pen. ^

押さえておくこと

ポイントは2つです。1つは空白を含む英文をどう読み込むか、もう1つは^ をどうやって真下に置くかです。

2行目も1行目と同じ文字数だけ1文字ずつ出力し、大文字の位置では ^、それ以外では空白を出せば、自然と位置がそろいます(半角文字は全部同じ幅なので)。

ヒント1空白を含めて読み込む

scanf("%s", s) は空白で止まるので、This is a Pen. だと This しか入りません。改行までをまとめて読むには次のように書きます。

scanf("%255[^\n]", s);

%[^\n] は「改行以外の文字を読めるだけ読む」という意味です。fgets(s, sizeof(s), stdin) でも読めますが、その場合は末尾に改行文字が入る点に注意が必要です。

ヒント22行目の作り方

1行目は printf("%s\n", s) でそのまま表示します。2行目は '\0' までループして、各文字について putchar で1文字ずつ出します。

  • 文頭ではなく(i != 0)、かつ大文字('A'〜'Z')なら putchar('^')
  • それ以外なら putchar(' ')

最後に putchar('\n') で改行します。

ヒント3長い文への対策

画面の幅より長い文だと、1行目が途中で折り返されて ^ の位置がずれてしまいます。

そこで、たとえば20文字ずつに区切って「文字列の行」と「^ の行」をペアで出力します。区切りの開始位置を start として、start を 20 ずつ増やす外側のループと、その20文字を処理する内側のループの二重ループにします。

解答例基本版
#include <stdio.h>

int main(void)
{
    char s[256];
    int i;

    printf("英文を入力: ");
    scanf("%255[^\n]", s);

    printf("%s\n", s);
    for (i = 0; s[i] != '\0'; i++) {
        if (i != 0 && s[i] >= 'A' && s[i] <= 'Z') {
            putchar('^');
        } else {
            putchar(' ');
        }
    }
    putchar('\n');
    return 0;
}

実行例

英文を入力: This is a Pen. This is a Pen. ^
  1. %255[^\n] で空白ごと1行を読み込みます。
  2. 1行目は文字列をそのまま表示します。
  3. 2行目は1文字ごとに ^ か空白を出すので、1行目とぴったり同じ位置関係になります。
  4. i != 0 で文頭(インデックス0)の T を除外しています。
解答例長い文への対策版
#include <stdio.h>

#define WIDTH 20   /* 1行に表示する文字数 */

int main(void)
{
    char s[256];
    int start, i;

    printf("英文を入力: ");
    scanf("%255[^\n]", s);

    for (start = 0; s[start] != '\0'; start += WIDTH) {
        /* 1行目: WIDTH 文字分を表示 */
        for (i = start; i < start + WIDTH && s[i] != '\0'; i++) {
            putchar(s[i]);
        }
        putchar('\n');

        /* 2行目: 大文字の真下に ^ */
        for (i = start; i < start + WIDTH && s[i] != '\0'; i++) {
            if (i != 0 && s[i] >= 'A' && s[i] <= 'Z') {
                putchar('^');
            } else {
                putchar(' ');
            }
        }
        putchar('\n');
    }
    return 0;
}

実行例

英文を入力: I think NASA and Tokyo are Great places to visit. I think NASA and Tok ^^^^ ^ yo are Great places ^ to visit.
  1. 外側のループで start を 0, 20, 40 … と進め、20文字ずつのブロックに分けます。
  2. 内側のループは、ブロックの終わりか '\0' のどちらか先に来たほうで止まります。
  3. ブロックごとに「文字列の行」と「^ の行」をセットで出すので、長い文でも位置がずれません。
  4. 1行の幅は #define WIDTH を変えるだけで調整できます。
さらに良くするなら:この方法だと Tokyo のように単語の途中で切れることがあります。区切り位置の手前の空白を探して、そこで改行すると読みやすくなります。また、. の直後の大文字も「文頭」とみなすと、複数の文を入力したときにも正しく判定できます。
解答例はどれも gcc でコンパイルし、上の実行例どおりに動くことを確認済みです。
