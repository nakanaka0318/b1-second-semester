1代入演算子・複合代入演算子

= は「等しい」ではなく右辺の値を左辺の変数に入れるという意味です。算術やビット演算と組み合わせた短縮形(複合代入)があります。

書き方同じ意味
a += 3a = a + 3
a -= 3a = a - 3
a *= 3a = a * 3
a /= 3a = a / 3
a %= 3a = a % 3
a &= b, a |= b, a ^= ba = a & b など
a <<= 2, a >>= 2a = a << 2 など

代入式そのものも値を持ちます(代入された値)。そのため a = b = 0; は右から順に b = 0、a = 0 と処理されます。

2インクリメント・デクリメント演算子

++ は1増やす、-- は1減らす演算子です。変数の前に付けるか後ろに付けるかで、式としての値が変わります。

書き方名前動き
++i前置先に増やして、増えた値を使う
i++後置今の値を使ってから、増やす
int i = 5;
int a = i++;   /* a = 5, i = 6 */
int b = ++i;   /* i = 7, b = 7 */

単独で i++; と書く場合(for 文の3つ目の欄など)は、前置でも後置でも結果は同じです。

注意:i = i++; や printf("%d %d", i++, i++); のように、1つの式の中で同じ変数を2回以上変更すると結果が決まりません(未定義動作)。

3関係演算子(比較)

2つの値を比べて、正しければ 1、間違っていれば 0 を返します。Cには true / false の型が元々無く、整数で表します。

演算子意味例(a=3, b=5)
==等しいa == b → 0
!=等しくないa != b → 1
<より小さいa < b → 1
>より大きいa > b → 0
<=以下a <= 3 → 1
>=以上b >= 6 → 0
よくあるミス:if (a = 5) は比較ではなく代入です。a に 5 が入り、式の値が 5(0以外=真)になるので、必ず実行されます。比較は ==。
数学の書き方は使えない:1 < x < 10 は (1 < x) < 10 と解釈され、前半の結果(0か1)を10と比べるので常に真になります。1 < x && x < 10 と書きます。

4論理演算子

条件を組み合わせる演算子です。Cでは 0 が偽、0以外はすべて真として扱い、結果は 1 か 0 になります。

演算子意味真になる条件
&&かつ(AND)両方が真
||または(OR)どちらかが真
!否定(NOT)元が偽(!0 → 1、!5 → 0)

短絡評価(ショートサーキット)

左側だけで結果が決まったら、右側は実行されません。

  • A && B:A が偽なら全体は偽に決まるので、B は評価しない
  • A || B:A が真なら全体は真に決まるので、B は評価しない
if (n != 0 && 100 / n > 5) {   /* n が 0 なら割り算は実行されない */
    ...
}

この性質を使うと、0 での割り算や配列の範囲外アクセスを防ぐ条件が書けます。

5ビット演算子・シフト演算子

整数を2進数で見て、1桁(1ビット)ずつ計算します。論理演算子(&& ||)とは別物です。

演算子名前働き例
&AND両方1なら112 & 10 → 8
|ORどちらか1なら112 | 10 → 14
^XOR違えば112 ^ 10 → 6
~NOT0と1を反転~0 → -1
<<左シフト左にずらす(×2ⁿ)3 << 2 → 12
>>右シフト右にずらす(÷2ⁿ)20 >> 1 → 10
12 = 1100 10 = 1010 -------- & 1000 = 8 | 1110 = 14 ^ 0110 = 6

よく使う形

  • (n & 1) == 0:偶数かどうか(一番下のビットが0なら偶数)
  • x | (1 << k):k番目のビットを1にする
  • x & ~(1 << k):k番目のビットを0にする
  • (x >> k) & 1:k番目のビットを取り出す
負の数の右シフトの結果は処理系によって異なります。ビット演算は unsigned の値で使うのが安全です。

6条件演算子(三項演算子)

条件 ? 値1 : 値2 の形で、条件が真なら値1、偽なら値2になります。Cで唯一、3つの項をとる演算子です。

max = (a > b) ? a : b;          /* 大きいほう */
abs = (x < 0) ? -x : x;         /* 絶対値 */
printf("%s\n", (n % 2 == 0) ? "偶数" : "奇数");

簡単な if-else を1行で書けますが、入れ子にすると読みにくくなるので、複雑な場合は if 文を使います。

9基本データ型の修飾子

char や int の前に付けて、符号の有無や大きさを変えるキーワードです。

修飾子働き
signed符号あり(負の数も扱う)。int は何も付けなければ signed
unsigned符号なし(0以上のみ)。同じサイズで正の範囲が約2倍
shortint を小さくする(通常2バイト)
longint を大きくする。long long でさらに大きく(8バイト)

主な型と範囲

サイズは環境によって変わります。下は Visual Studio(Windows)での値です。

型バイト範囲printf
signed char1-128 〜 127%d
unsigned char10 〜 255%u
short2-32,768 〜 32,767%hd
unsigned short20 〜 65,535%hu
int4約 -21億 〜 21億%d
unsigned int40 〜 約42億%u
long4int と同じ%ld
long long8約 ±9.2×10¹⁸%lld
unsigned long long80 〜 約1.8×10¹⁹%llu

n バイトの型は 28n 通りの値を持てます。符号ありはその半分を負の数に使うので、1バイトなら -128〜127、符号なしなら 0〜255 です。

  • short は short int、unsigned は unsigned int の省略形です。
  • long は Windows では4バイト、Linux(64ビット)では8バイトです。確実に8バイトが欲しいときは long long を使います。
  • ただの char が signed か unsigned かは処理系しだいです。数値として使うなら signed char / unsigned char と明示します。

オーバーフロー(範囲を超えたとき)

  • unsigned:範囲を超えると一周して戻ります(255 + 1 → 0、0 - 1 → 最大値)。これは規格で決まった動作です。
  • signed:計算結果が範囲を超えるのは未定義動作です。多くの環境では 127 + 1 が -128 になりますが、当てにしてはいけません。
signed と unsigned を混ぜない:int と unsigned int を比べると、int 側が unsigned に変換されます。-1 は約42億になるので、-1 < 1u が偽になります。

10型修飾子 const と volatile

値の範囲ではなく、変数の扱い方を指定する修飾子です。

  • const:値を変更できない変数にする。代入しようとするとコンパイルエラーになります。宣言と同時に初期化します。
  • volatile:プログラムの外(ハードウェアや割り込みなど)で値が変わる可能性があることを示し、コンパイラの最適化で読み込みが省かれないようにします。組み込み系で使い、普段の課題ではほぼ出てきません。
const int MAX = 100;
MAX = 200;              /* エラー:const は変更できない */

const double PI = 3.14159;
double area = PI * r * r;

#define MAX 100 と似ていますが、const は型を持つ変数なので、型チェックが効き、デバッガでも値を確認できます。

Q練習問題

各コードを実行したときの出力を答えてください。int は4バイトとします。

問1 複合代入
int a = 5;
a += 3;
a *= 2;
printf("%d\n", a);
答え16

a += 3 で 8、a *= 2 で 16 になります。

問2 前置と後置
int i = 3;
int x = i++ * 2;
printf("%d %d\n", x, i);
int y = ++i * 2;
printf("%d %d\n", y, i);
答え6 4 / 10 5
6 4 10 5

i++ は今の値 3 を使ってから i を 4 にするので、x = 3 × 2 = 6。++i は先に i を 5 にしてから使うので、y = 5 × 2 = 10 です。

問3 比較と論理
printf("%d %d %d\n", 3 > 2 && 5 < 1, !0, 7 > 3 > 1);
答え0 1 0
  • 3 > 2 は 1、5 < 1 は 0。1 かつ 0 なので 0。
  • !0 は 0 の否定で 1。
  • 7 > 3 > 1 は (7 > 3) > 1 → 1 > 1 → 0。数学のようには読まれません。
問4 短絡評価
int p = 0, q = 0;
if (p++ || q++) { }
printf("%d %d\n", p, q);

p = 0; q = 0;
if (p++ && q++) { }
printf("%d %d\n", p, q);
答え1 1 / 1 0
1 1 1 0

p++ の値は 0(偽)です。|| は左が偽なので右の q++ も実行され、両方 1 になります。

&& は左が偽の時点で全体が偽に決まるので、q++ は実行されず q は 0 のままです。

問5 ビット演算
printf("%d %d %d %d\n", 12 & 10, 12 | 10, 12 ^ 10, ~0);
答え8 14 6 -1

12 = 1100、10 = 1010。AND は 1000 = 8、OR は 1110 = 14、XOR は 0110 = 6。

~0 は全ビットが1になります。signed int で全ビット1は -1 を表します。

問6 シフトと優先順位
printf("%d %d %d\n", 3 << 2, 20 >> 1, 1 + 2 << 1);
答え12 10 6

3 << 2 は 3 × 4 = 12、20 >> 1 は 20 ÷ 2 = 10。

1 + 2 << 1 は + のほうが優先されるので (1 + 2) << 1 = 3 × 2 = 6 です。1 + (2 << 1) = 5 ではありません。

問7 偶数判定のバグ

次のコードは n が偶数なら 1 を表示するつもりです。n = 4 のとき何が表示されるか答え、正しく直してください。

int n = 4;
printf("%d\n", n & 1 == 0);
答え0 と表示される

== のほうが & より優先順位が高いので、n & (1 == 0) → n & 0 → 0。n が何であっても常に 0 です。

printf("%d\n", (n & 1) == 0);   /* 1 と表示される */
問8 条件演算子
int j = 5;
int r = j > 3 ? j * 2 : j + 1;
printf("%d\n", r);
答え10

j > 3 は真なので、j * 2 = 10 が選ばれます。

問9 sizeof
int arr[10];
printf("%zu %zu %zu\n", sizeof(char), sizeof(int), sizeof(arr));
答え1 4 40

char は常に1バイト。int は4バイト。配列に sizeof を使うと配列全体のサイズになるので、4 × 10 = 40 です。

問10 キャスト
printf("%.1f %d %d\n", (double)7 / 2, (int)3.99, (int)-3.99);
答え3.5 3 -3

(double)7 / 2 はキャストが先に効くので 7.0 / 2 = 3.5。(double)(7 / 2) と書くと、先に整数どうしの割り算で 3 になってしまい 3.0 です。

整数へのキャストは0に向かって切り捨てなので、3.99 → 3、-3.99 → -3(-4 ではない)。

問11 unsigned char の範囲
unsigned char c = 255;
c++;
printf("%d\n", c);

unsigned char d = 300;
printf("%d\n", d);
答え0 / 44
0 44

unsigned char は 0〜255 なので、255 + 1 は一周して 0 になります。

300 は範囲外なので 256 で割った余りになり、300 − 256 = 44 です(コンパイラが警告を出します)。

問12 unsigned int の 0 − 1
unsigned int u = 0;
u = u - 1;
printf("%u\n", u);
答え4294967295

unsigned は負の数を持てないので、0 − 1 は一周して最大値 232 − 1 = 4294967295 になります。

問13 signed と unsigned の比較
unsigned int u = 1;
int k = -1;
if (k < u) printf("小さい\n");
else       printf("小さくない\n");
答え小さくない

int と unsigned int を比べると、k が unsigned に変換されます。-1 は 4294967295 になるので、4294967295 < 1 は偽です。符号の違う型を比べないか、キャストで型をそろえます。

問14 複合代入とビット
int v = 10;
v <<= 2;
v ^= 1;
printf("%d\n", v);
答え41

v <<= 2 で 10 × 4 = 40(101000)。v ^= 1 で一番下のビットが反転して 101001 = 41 です。

問15 型を選ぶ

次の値を入れるのに適した型を答えてください(Visual Studio の場合)。

  1. 年齢(0〜150)をなるべく小さいメモリで
  2. 30億
  3. 地球の人口(約80億)
  4. 気温(−50〜60 の整数)をなるべく小さいメモリで
答え型の選び方
  1. unsigned char(0〜255)
  2. unsigned int(〜約42億)。int は約21億までなので入らない。long long でも可。
  3. long long。unsigned int でも約42億までなので足りない。Windows の long は4バイトなので不可。
  4. signed char(-128〜127)。負の数があるので unsigned は使えない。
問16 const

次のコードをコンパイルするとどうなるか答えてください。

const int N = 5;
N = N + 1;
printf("%d\n", N);
答えコンパイルエラー

const を付けた変数には代入できません。Visual Studio では「式は変更可能な左辺値である必要があります」といったエラーになります。
